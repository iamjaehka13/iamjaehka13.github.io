Framing example · One project, six framings

같은 스마트글래스와 책상 정리 robot, 무엇을 논문으로 남길까

hardware와 task를 고정하고 primary contribution만 바꿔 venue fit의 차이를 본다.

Constant project

사용자는 스마트글래스의 gaze·speech·gesture로 cluttered desk의 정리 목표를 전달하고, mobile manipulator는 모호한 지시를 확인한 뒤 물건을 분류·이동한다.

CHIattention·interaction burden·error recovery

Gaze·voice·AR confirmation을 결합한 interaction technique가 사용자의 attention switching, interaction burden과 error-recovery strategy를 어떻게 바꾸는가?

Evidence: comparative user study, attention·correction behavior, workload와 reusable HCI design implication.

HRI상호작용 mechanism과 recovery

Robot이 불확실성을 질문과 motion cue로 드러낼 때 사용자의 correction과 joint-task recovery가 어떻게 달라지는가?

Evidence: interaction-specific behavioral result와 system evidence, reusable HRI mechanism.

RO-MANreference와 역할의 협상

Gaze·speech·gesture가 충돌할 때 human–robot team은 object reference와 task ownership을 어떻게 협상하는가?

Evidence: communication protocol, team metric, breakdown·repair, role negotiation.

ICRA · IROS새로운 integrated capability

Deictic command grounding, active clarification, task-and-motion planning을 통합해 cluttered manipulation의 recovery rate를 높인다.

Evidence: robotics baseline·ablation, real-robot success, latency·safety·failure analysis.

RSS검증 가능한 하나의 principle

Ambiguous human input을 belief update와 query action으로 함께 다루는 uncertainty-aware shared-autonomy principle을 제안한다.

Evidence: formulation, strongest baseline, ablation·failure boundary, expert-verifiable core.

CoRLhuman signal로 학습·일반화

Sparse gaze·language correction으로 tidying policy를 personalize하고 unseen object와 desk layout으로 transfer한다.

Evidence: learning curve, data efficiency, baseline·ablation, generalization과 convincing robot transfer.
