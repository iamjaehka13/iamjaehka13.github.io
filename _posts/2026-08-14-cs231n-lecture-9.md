## **0. 이 글의 목표**

[Lecture 8의 Attention과 Transformer](/posts/cs231n-lecture-8/)는 vector 집합 사이의 정보 교환과 Vision Transformer의 patch tokenization을 다뤘다. 이번에는 image 하나를 class 하나로 바꾸는 분류를 넘어, **어디에 무엇이 있고 같은 class의 여러 개체를 어떻게 구분하며 model이 어느 공간을 근거로 반응했는지**를 다룬다.

핵심 질문은 다음과 같다.

- Image 전체의 label 하나를 pixel마다의 label로 확장하는 방법
- Downsampling으로 사라진 spatial resolution을 되살리는 방법
- 개수가 달라지는 object set을 고정된 neural-network 계산으로 표현하는 방법
- R-CNN, Fast R-CNN, Faster R-CNN이 반복 계산을 줄이는 범위
- YOLO와 DETR이 detection output을 구성하는 서로 다른 방식
- Semantic segmentation과 instance segmentation의 차이
- Saliency, CAM, Grad-CAM이 계산하는 값과 그 해석의 한계

핵심은 **분류 이후의 spatial prediction에서 공간 정보를 얼마나 보존할지, 가변 개수의 객체를 어떤 출력 구조로 표현할지, 그리고 예측의 근거를 어느 수준까지 추적할지**에 있다.

## **1. Image classification 이후의 spatial prediction**

같은 image를 입력으로 받아도 task마다 정답의 단위가 다르다.

![Image classification에서 semantic segmentation, object detection과 instance segmentation으로 출력 단위가 확장되는 전체 비교]({{ '/assets/img/posts/cs231n-lecture-9/animations/vision-task-taxonomy.gif' | relative_url }})

| Task | 출력 | 공간 정보 | 같은 class의 여러 instance |
|---|---|---|---|
| Image classification | Image당 class 하나 | 없음 | 구분하지 않음 |
| Semantic segmentation | Pixel마다 class 하나 | Pixel 단위 | 같은 label로 합쳐짐 |
| Object detection | $(class, box)$의 가변 집합 | Box 단위 | 서로 다른 box로 구분 |
| Instance segmentation | $(class, box, mask)$의 가변 집합 | Pixel과 instance 단위 | 서로 다른 mask로 구분 |

Semantic segmentation을 두고 "object가 없고 pixel만 있다"고 표현할 때 object가 실제 장면에 없다는 뜻은 아니다. Model이 **instance ID를 출력하지 않는다**는 뜻이다. 고양이가 두 마리 있어도 둘 다 `cat` label을 받고, 어느 pixel이 첫 번째 고양이에 속하는지는 알 수 없다.

Detection은 pixel mask 대신 object마다 box를 출력한다. Instance segmentation은 detection의 instance 분리와 segmentation의 pixel 경계를 결합한다. 네 task는 단순히 출력 해상도만 다른 문제가 아니라 **정답의 자료구조가 다른 문제**다.

## **2. Semantic segmentation의 pixel-wise classification**

입력 image가 $X\in\mathbb{R}^{3\times H\times W}$이고 class 수가 $C$라면 semantic-segmentation model은 pixel마다 $C$개의 logit을 만든다.

$$
S
\in
\mathbb{R}^{C\times H\times W}
$$

Inference에서는 각 위치의 가장 큰 logit을 label로 선택한다.

$$
\hat y_{h,w}
=
\operatorname*{argmax}_{c}
S_{c,h,w}
$$

Training에서는 label이 있는 pixel 집합 $\Omega$에 대해 cross-entropy를 합하거나 평균한다.

$$
\mathcal L_{\mathrm{seg}}
=
-\frac{1}{|\Omega|}
\sum_{(h,w)\in\Omega}
\log
\frac{\exp S_{y_{h,w},h,w}}
{\sum_{c=1}^{C}\exp S_{c,h,w}}
$$

Image classification의 loss가 image당 한 번 생긴다면 segmentation의 loss는 pixel마다 생긴다. 그렇다고 pixel을 독립적으로 처리하면 되는 것은 아니다. RGB 값 하나만 보고 그 pixel이 소인지 풀인지 결정하기는 어렵다. Texture, boundary, 주변 object와 장면 context가 함께 필요하다.

### **2.1 Sliding-window prediction의 context·계산 병목**

가장 직접적인 방법은 각 pixel 주변 patch를 잘라 CNN classifier에 넣는 sliding window다. Patch는 context를 주지만, 서로 이웃한 두 patch는 대부분의 pixel을 공유한다. 같은 convolution을 거의 같은 영역에서 반복하게 된다.

![Pixel 하나의 context 부족에서 patch sliding window의 반복 계산을 거쳐 whole-image convolution과 fully convolutional encoder-decoder에 도달하는 전체 과정]({{ '/assets/img/posts/cs231n-lecture-9/animations/semantic-segmentation-fcn.gif' | relative_url }})

Convolution은 spatial location 전체에서 weight를 공유하므로 image 전체를 한 번 통과시키면 겹치는 patch 계산을 재사용할 수 있다. Fully convolutional network는 fully connected classifier를 spatial convolution으로 바꾸고 위치마다 class logit을 출력한다.

문제는 resolution이다. 모든 intermediate feature를 원본 $H\times W$로 유지하면 parameter 수가 늘어나는 것이 아니라 **activation memory와 FLOPs가 크게 늘어난다**. Convolution parameter 수는 kernel과 channel 수로 정해지며 spatial size와 무관하다.

반대로 [stride와 pooling](/posts/cs231n-lecture-5/#5-output-size-padding-stride)으로 feature map을 줄이면 넓은 [receptive field](/posts/cs231n-lecture-5/#6-receptive-field-한-activation이-보는-원본-범위)를 효율적으로 얻지만 output이 거칠어진다. 그래서 dense predictor는 보통 다음 두 부분으로 나뉜다.

$$
\text{high-resolution image}
\xrightarrow{\text{encoder}}
\text{low-resolution semantic feature}
\xrightarrow{\text{decoder}}
\text{high-resolution logits}
$$

Encoder는 context와 semantic abstraction을 모으고 decoder는 spatial resolution을 복원한다.

## **3. Encoder-decoder segmentation의 resolution 회복**

Downsampling된 feature map의 크기를 키우는 방법은 모두 같지 않다. 어떤 방법은 값을 정해진 규칙으로 복사하고, 어떤 방법은 encoder가 남긴 위치 정보를 재사용하며, 어떤 방법은 kernel 자체를 학습한다.

### **3.1 고정 upsampling과 max-unpooling**

Nearest-neighbor upsampling은 각 값을 주변 위치에 반복한다. Zero-insertion 또는 bed-of-nails 방식은 원래 값 사이에 0을 넣는다. 둘 다 learnable parameter가 없는 고정 연산이다.

Max-unpooling은 [max pooling](/posts/cs231n-lecture-5/#91-max-pooling) 때 선택된 argmax index를 저장해 두었다가 decoder에서 그 위치에 값을 되돌린다. 이 방식은 최대값이 있었던 위치를 보존하지만 pooling이 버린 나머지 값까지 복원하지는 못한다.

![Nearest-neighbor와 max-unpooling에서 stride convolution, transposed convolution의 overlap-add와 matrix transpose 관점까지 이어지는 전체 upsampling 설명]({{ '/assets/img/posts/cs231n-lecture-9/animations/upsampling-transposed-convolution.gif' | relative_url }})

### **3.2 Transposed convolution의 선형 연산 관점**

Convolution을 input vector $x$에 sparse matrix $C$를 곱하는 선형 연산으로 쓰면

$$
y=Cx
$$

가 된다. 이에 대응하는 transposed convolution은

$$
\widetilde x=C^{\mathsf T}y
$$

를 계산한다. 이름의 `transposed`는 이 matrix transpose에서 나온다. Input tensor 자체를 transpose하는 연산도 아니고, 일반적인 convolution의 inverse도 아니다. Stride나 pooling으로 잃은 정보를 수학적으로 되찾는 것이 아니라 **고해상도 output을 만드는 learnable linear map**이다.

Stride $s$, padding $p$, dilation $d$, kernel size $k$, output padding $o$인 1D transposed convolution의 길이는

$$
L_{\mathrm{out}}
=
(L_{\mathrm{in}}-1)s
-2p
+d(k-1)
+o
+1
$$

이다. 각 input 값은 kernel 전체를 곱한 patch를 output에 놓고, 이웃 input이 만든 patch가 겹치면 값을 더한다. $[a,b]$ input과 $[x,y,z]$ kernel의 1D 예제에서도 weighted kernel이 겹치는 위치마다 합산된다.

Kernel과 stride의 overlap 횟수가 위치마다 고르지 않으면 checkerboard artifact가 생길 수 있다. 먼저 bilinear 또는 nearest-neighbor resize를 수행한 뒤 일반 convolution을 적용하는 방식은 이런 artifact를 줄이기 위한 흔한 대안이다.

### **3.3 U-Net의 skip concatenation**

Encoder의 깊은 feature는 넓은 context를 담지만 위치가 거칠다. Decoder가 bottleneck만 보고 mask를 복원하면 작은 구조와 object boundary가 흐려질 수 있다.

![Fully convolutional encoder-decoder에서 U-Net의 downsampling path, upsampling path와 같은 scale의 skip feature concatenation으로 이어지는 전체 구조]({{ '/assets/img/posts/cs231n-lecture-9/animations/unet-skip-connections.gif' | relative_url }})

U-Net은 encoder와 decoder의 같은 resolution 사이를 skip connection으로 연결한다.

$$
D_l
=
\operatorname{Conv}
\left(
\operatorname{Concat}
\left[
\operatorname{Up}(D_{l+1}),
E_l
\right]
\right)
$$

$E_l$은 encoder의 high-resolution feature, $D_l$은 decoder feature다. 이 skip은 [ResNet의 residual addition](/posts/cs231n-lecture-6/#6-resnet과-깊은-network의-optimization-degradation)과 다르다. U-Net의 대표 구조는 channel 축 **concatenation**으로 fine spatial detail을 다시 공급한다.

Contracting path는 context를 모으고 expanding path는 resolution을 복원한다. 의료영상처럼 경계 정밀도가 중요한 task에서 U-Net 계열이 오래 사용되는 이유도 이 두 정보의 결합에 있다.

Semantic segmentation의 output은 여전히 class map 하나다. 같은 class object가 여러 개라면 각각의 instance identity는 남지 않는다.

## **4. Object localization의 classification·box regression**

Object가 하나라고 가정하면 image classification에 bounding-box regression head를 추가할 수 있다.

![Single-object image에서 class score와 bounding-box 좌표를 함께 예측하고 두 loss를 결합하는 localization의 전체 과정]({{ '/assets/img/posts/cs231n-lecture-9/animations/single-object-localization.gif' | relative_url }})

Shared backbone feature $z$에서 class logit과 box를 각각 예측한다.

$$
\hat p
=
f_{\mathrm{cls}}(z),
\qquad
\hat b
=
f_{\mathrm{box}}(z)
$$

Box는 $(x,y,w,h)$, $(c_x,c_y,w,h)$ 또는 $(x_1,y_1,x_2,y_2)$처럼 표현할 수 있다. 서로 다른 parameterization을 섞으면 loss와 decoding이 맞지 않으므로 convention을 먼저 고정해야 한다.

### **4.1 Bounding-box multitask loss**

Single-object localization의 기본 목적함수는 classification loss와 localization loss의 가중합이다.

$$
\mathcal L
=
\mathcal L_{\mathrm{cls}}
+\lambda
\mathcal L_{\mathrm{box}}
$$

여기서는 단순화를 위해 L2 localization loss를 사용한다. 이 식의 핵심은 L2 자체가 아니라 **하나의 visual representation이 category와 geometry를 동시에 설명하도록 학습한다는 점**이다. 실제 detector는 L1, Smooth L1, IoU, GIoU 계열 loss를 사용할 수 있으며 $\lambda$는 서로 다른 loss scale을 조절한다.

Single-object localization은 output dimension이 항상 $C+4$로 고정된다. 여러 object가 등장하면 image마다 box 수가 달라지므로 이 고정 vector만으로는 충분하지 않다.

## **5. 가변 객체 집합의 검출**

Detection의 정답은 순서 없는 가변 길이 집합이다.

$$
Y
=
\left\{
(c_i,b_i)
\right\}_{i=1}^{M},
\qquad
M=M(X)
$$

Object 수 $M$은 image마다 달라진다. Network의 tensor 계산은 고정된 shape를 선호하므로, detector는 많은 candidate를 만든 뒤 줄이거나 fixed number of slots에 object와 no-object를 배정한다.

### **5.1 Dense candidate와 region proposal**

모든 위치, scale, aspect ratio의 crop을 classifier에 넣는 brute-force sliding window는 가능하지만 candidate 수가 폭발한다.

![Single-object output의 고정 크기 문제에서 모든 crop의 brute-force 분류와 Selective Search region proposal로 이어지는 전체 동기]({{ '/assets/img/posts/cs231n-lecture-9/animations/multi-object-region-proposals.gif' | relative_url }})

Region proposal은 object가 있을 법한 작은 candidate set을 먼저 만든다. 초기 R-CNN은 Selective Search 같은 hand-designed proposal algorithm을 사용했다. 이후 Faster R-CNN은 proposal 자체도 network가 학습하도록 바꾼다.

### **5.2 IoU와 non-maximum suppression**

두 box $A,B$의 overlap은 Intersection over Union으로 측정한다.

$$
\operatorname{IoU}(A,B)
=
\frac{|A\cap B|}
{|A\cup B|}
$$

Dense detector는 같은 object 주위에 점수가 높은 box를 여러 개 만들 수 있다. Non-maximum suppression은 다음 순서를 반복한다.

1. 남은 box 중 score가 가장 큰 box를 선택한다.
2. 선택한 box와 IoU가 threshold보다 큰 낮은-score box를 제거한다.
3. Candidate가 없을 때까지 반복한다.

NMS는 object를 찾는 model 자체가 아니라 **중복 candidate를 정리하는 post-processing**이다. Threshold가 너무 낮으면 가까운 두 object 중 하나를 지울 수 있고 너무 높으면 duplicate가 남는다.

## **6. R-CNN 계열의 feature sharing**

R-CNN, Fast R-CNN, Faster R-CNN의 차이는 이름보다 **어디까지 계산을 공유하는지**로 보는 편이 명확하다.

### **6.1 R-CNN의 per-region backbone 반복**

R-CNN은 region proposal을 고정 크기로 warp한 뒤 각 region을 pretrained ConvNet에 독립적으로 통과시킨다. Region feature를 SVM으로 분류하고 별도의 regressor로 box를 보정한다.

![Region proposal에서 warp, proposal별 ConvNet, SVM과 bounding-box regression을 거쳐 반복 forward-pass 병목과 Fast R-CNN의 핵심 아이디어에 도달하는 R-CNN 전체 구조]({{ '/assets/img/posts/cs231n-lecture-9/animations/rcnn-pipeline.gif' | relative_url }})

Proposal이 약 2,000개라면 image 한 장에서 backbone forward가 약 2,000번 필요하다. 이 병목은 classifier head보다 convolutional feature extraction의 반복에서 생긴다. Pretrained feature를 detection task에 fine-tuning한다는 발상은 [transfer learning](/posts/cs231n-lecture-6/#9-데이터-양과-domain-차이에-따른-transfer-learning-전략)과 연결된다.

### **6.2 Fast R-CNN의 shared feature map**

Fast R-CNN은 순서를 뒤집는다. Image 전체에 backbone을 한 번 적용하고, proposal에 해당하는 영역을 shared feature map에서 crop해 고정 크기로 바꾼다.

![Image 전체 backbone의 한 번 계산, shared feature map의 RoI crop·resize, per-region network와 class·box head로 완성되는 Fast R-CNN]({{ '/assets/img/posts/cs231n-lecture-9/animations/fast-rcnn-feature-sharing.gif' | relative_url }})

$$
F
=
\operatorname{Backbone}(X),
\qquad
z_i
=
\operatorname{RoIPool}(F,b_i)
$$

$$
\hat p_i
=
f_{\mathrm{cls}}(z_i),
\qquad
\Delta\hat b_i
=
f_{\mathrm{box}}(z_i)
$$

Backbone feature가 원 image와 spatial correspondence를 유지하므로 proposal마다 full CNN을 반복할 필요가 없다. 다만 proposal은 여전히 외부 Selective Search에 의존한다.

### **6.3 RoI Pool과 RoI Align의 좌표 정렬**

Proposal box는 원 image의 연속 좌표에 있고 feature map은 stride 때문에 더 작은 grid다. RoI Pool은 box를 feature 좌표로 projection한 뒤 경계와 bin을 integer grid에 snap하고 각 bin에서 max pooling한다.

![Proposal을 feature map에 투영하고 좌표를 grid에 snap한 뒤 고정 bin으로 나누면서 spatial misalignment가 생기는 RoI Pool의 전체 과정]({{ '/assets/img/posts/cs231n-lecture-9/animations/roi-pool.gif' | relative_url }})

고정 크기 output을 쉽게 얻지만 coordinate quantization이 object와 pooled feature의 정렬을 흔든다. Classification은 작은 shift에 견딜 수 있어도 pixel-accurate mask에는 이 오차가 크게 작용한다.

RoI Align은 proposal coordinate를 반올림하지 않는다. 각 output bin에서 regular sample point를 잡고 네 이웃 feature를 bilinear interpolation한다.

![Coordinate snapping 없이 fractional sample point와 네 이웃 feature의 bilinear interpolation을 이용하는 RoI Align의 전체 과정]({{ '/assets/img/posts/cs231n-lecture-9/animations/roi-align.gif' | relative_url }})

$$
f(x,y)
=
\sum_{i=1}^{2}
\sum_{j=1}^{2}
f(x_i,y_j)
\max(0,1-|x-x_i|)
\max(0,1-|y-y_j|)
$$

Input feature가 $F\in\mathbb{R}^{B\times C\times H_f\times W_f}$이고 전체 RoI가 $K$개라면 output은

$$
Z
\in
\mathbb{R}^{K\times C\times H_o\times W_o}
$$

가 된다. RoI Align도 fixed spatial size를 만드는 연산이지만 initial coordinate snapping을 없앤다는 차이가 있다.

### **6.4 Faster R-CNN의 region proposal network**

Faster R-CNN은 external proposal algorithm을 Region Proposal Network로 바꾼다. RPN은 backbone feature map의 각 위치에 여러 scale과 aspect ratio의 anchor를 **dense하게 배치**하고 각 anchor의 objectness와 box offset을 예측한다.

![Feature map의 dense anchor에서 objectness, box correction, 여러 anchor와 top proposal 선택으로 이어지는 Region Proposal Network]({{ '/assets/img/posts/cs231n-lecture-9/animations/region-proposal-network.gif' | relative_url }})

Feature map 크기가 $H_f\times W_f$이고 위치마다 anchor가 $K$개라면 output shape는 다음과 같다.

$$
\text{objectness logits}
\in
\mathbb{R}^{K\times H_f\times W_f}
$$

$$
\text{box transforms}
\in
\mathbb{R}^{4K\times H_f\times W_f}
$$

위 식은 anchor마다 binary sigmoid logit 하나를 두는 convention이다. Original Faster R-CNN처럼 foreground/background two-class softmax를 쓰면 objectness output은 $2K\times H_f\times W_f$이고, box transform은 두 경우 모두 $4K\times H_f\times W_f$다.

Objectness 상위 candidate를 고르고 box correction을 적용한 뒤 NMS와 top-$K$ 선택으로 second-stage proposal을 만든다. RPN과 detection head는 같은 backbone feature를 공유한다.

### **6.5 Two-stage detector의 네 가지 loss**

Faster R-CNN의 training objective는 proposal stage와 RoI stage의 classification·regression을 합친다.

$$
\mathcal L
=
\mathcal L_{\mathrm{rpn\_cls}}
+\mathcal L_{\mathrm{rpn\_box}}
+\mathcal L_{\mathrm{roi\_cls}}
+\mathcal L_{\mathrm{roi\_box}}
$$

![External proposal의 runtime 병목, learned RPN, 네 가지 loss와 two-stage 구조 및 detector 설계 변수로 이어지는 Faster R-CNN의 세부 흐름]({{ '/assets/img/posts/cs231n-lecture-9/animations/faster-rcnn-details.gif' | relative_url }})

First stage는 class를 세밀하게 구분하기보다 object가 있을 법한 region을 좁힌다. Second stage는 정렬된 RoI feature를 이용해 category와 box를 더 정교하게 예측한다.

## **7. Single-stage detector의 dense prediction**

Two-stage detector는 proposal과 per-RoI refinement를 분리한다. Single-stage detector는 feature grid에서 class와 box를 한 번에 dense prediction한다.

### **7.1 YOLO의 grid·box·class output**

Original YOLO v1은 image를 $S\times S$ grid로 나누고 각 cell에서 $B$개의 box와 confidence, $C$개의 class score를 예측한다.

$$
\text{output shape}
=
S\times S\times(5B+C)
$$

![Two-stage detector와 single-stage detector의 차이에서 YOLO grid, cell별 box·confidence·class output, 많은 candidate와 최종 detection으로 이어지는 전체 과정]({{ '/assets/img/posts/cs231n-lecture-9/animations/yolo-grid-detection.gif' | relative_url }})

모든 cell의 candidate는 shared network의 한 forward pass에서 나온다. YOLO v1의 box confidence는 $\Pr(\mathrm{Object})\times\operatorname{IoU}(\mathrm{pred},\mathrm{truth})$를 목표로 하고, cell의 class output은 $\Pr(\mathrm{class}\mid\mathrm{Object})$를 나타낸다. Inference에서는 둘을 곱한 class별 box score를 이용해 confidence threshold와 NMS로 겹치는 box를 줄인다. Proposal generator와 second-stage head를 따로 실행하지 않는 것이 구조적 차이다.

정확한 $S\times S\times(5B+C)$ layout과 cell responsibility는 YOLO v1의 설계이며, 후속 YOLO 계열의 공통 규칙은 아니다.

### **7.2 One-stage와 two-stage detector의 구조적 차이**

| 비교 축 | Two-stage detector | Single-stage detector |
|---|---|---|
| Candidate 생성 | RPN 등 first stage | Feature grid의 dense output |
| Refinement | Proposal별 second stage | 같은 prediction head에서 직접 처리 |
| Feature 공유 | Backbone 공유 후 RoI 연산 | 전체 dense head에서 공유 |
| Output 정리 | Proposal NMS와 final NMS | Dense candidate threshold와 NMS |
| 대표 구조 | Faster R-CNN | Original YOLO, SSD, RetinaNet |

One-stage와 two-stage는 정확도와 속도를 자동으로 결정하는 이름이 아니다. Backbone, feature pyramid, resolution, assignment, loss와 post-processing에 따라 결과가 달라진다. 지속되는 차이는 **proposal-conditioned refinement를 별도 stage로 두는지**다.

## **8. DETR의 set prediction**

DETR는 detection을 dense anchor classification이나 proposal refinement가 아니라 **fixed-size set prediction**으로 다시 정의한다.

![CNN image feature와 positional encoding, Transformer encoder, learned object query, decoder와 class·box·no-object output으로 완성되는 DETR]({{ '/assets/img/posts/cs231n-lecture-9/animations/detr-set-prediction.gif' | relative_url }})

Original DETR의 encoder input은 CNN feature map을 flatten한 image token이고, [ViT](/posts/cs231n-lecture-8/#9-vision-transformer의-patch-tokenization)의 input은 raw patch를 직접 projection한 token이라는 차이가 있다.

Encoder가 image token을 처리한 뒤 decoder에는 $N$개의 learned object query가 들어간다. Query는 미리 특정 class나 위치를 담당하도록 정해진 anchor가 아니라 학습되는 prediction slot이다. Decoder self-attention은 query 사이의 관계를 처리하고 [cross-attention](/posts/cs231n-lecture-8/#32-cross-attention의-matrix-계산)은 image feature에서 query별 정보를 읽는다.

각 query $i$는 class distribution과 normalized box를 출력한다.

$$
\hat y_i
=
\left(
\hat p_i,
\hat b_i
\right),
\qquad
i=1,\ldots,N
$$

실제 object가 query 수보다 적으면 남은 slot은 no-object class가 된다. 반대로 object가 query 수보다 많으면 architecture상 모두 출력할 수 없으므로 dataset의 object count를 감당할 만큼 $N$을 크게 잡아야 한다.

### **8.1 Object query와 bipartite matching**

Fixed query만으로 duplicate box가 사라지는 것은 아니다. Canonical DETR의 핵심은 prediction과 ground truth를 **one-to-one으로 배정하는 Hungarian bipartite matching**이다.

![DETR의 fixed prediction slot, class·box matching cost matrix, Hungarian one-to-one assignment와 set loss]({{ '/assets/img/posts/cs231n-lecture-9/diagrams/detr-bipartite-matching.svg' | relative_url }})

실제 ground-truth object가 $M<N$개라면 $\varnothing$인 no-object target을 더해 $N$개 slot으로 맞춘다. 이 target을 $y_j=(c_j,b_j)$, prediction을 $\hat y_i=(\hat p_i,\hat b_i)$라 하면 실제 object와 prediction 사이의 class·box matching cost를 만든다. 그 합이 최소인 permutation을 선택한다.

$$
\hat\sigma
=
\operatorname*{argmin}_{\sigma\in\mathfrak S_N}
\sum_{j=1}^{N}
\mathbf 1[c_j\neq\varnothing]
\mathcal C_{\mathrm{match}}
\left(
y_j,
\hat y_{\sigma(j)}
\right)
$$

Training에서는 모든 slot에 object class 또는 no-object classification loss를 주고, 실제 object와 matched된 slot에만 direct box loss를 적용한다.

$$
\mathcal L_{\mathrm{DETR}}
=
\sum_{j=1}^{N}
\left[
-\log \hat p_{\hat\sigma(j)}(c_j)
+\mathbf 1[c_j\neq\varnothing]
\left(
\lambda_1
\left\|
b_j-\hat b_{\hat\sigma(j)}
\right\|_1
+\lambda_{\mathrm{giou}}
\mathcal L_{\mathrm{GIoU}}
\right)
\right]
$$

한 target에는 prediction 하나만 대응하므로 여러 query가 같은 object를 반복 예측하면 손해를 본다. 이 set loss가 unique prediction을 학습하게 하므로 canonical DETR는 anchor generation과 별도 NMS를 제거할 수 있다.

"Box transform regression이 없다"는 표현은 box regression 자체가 없다는 뜻이 아니다. Anchor-relative offset 대신 normalized box coordinate를 직접 regress한다는 뜻이다. 또한 이 성질은 canonical DETR에 대한 설명이며 모든 Transformer detector가 anchor와 NMS를 쓰지 않는다는 보편 규칙은 아니다.

## **9. Instance segmentation과 Mask R-CNN**

Semantic segmentation은 같은 class의 여러 object를 합친다. Mask R-CNN은 Faster R-CNN이 분리한 proposal마다 mask를 예측해 instance identity를 보존한다.

![Object detection에서 instance segmentation, Faster R-CNN의 class·box head와 per-RoI mask head, instance별 mask target과 결과 및 pose extension으로 이어지는 Mask R-CNN 전체 과정]({{ '/assets/img/posts/cs231n-lecture-9/animations/mask-rcnn-instance-segmentation.gif' | relative_url }})

Faster R-CNN의 class branch와 box branch 옆에 small fully convolutional mask branch를 병렬로 추가한다.

$$
z_i
=
\operatorname{RoIAlign}(F,b_i)
$$

$$
\hat p_i
=
f_{\mathrm{cls}}(z_i),
\qquad
\Delta\hat b_i
=
f_{\mathrm{box}}(z_i),
\qquad
\hat M_i
=
f_{\mathrm{mask}}(z_i)
$$

Foreground class가 $K$개인 class-specific head의 대표적인 RoI별 output shape는

$$
\text{class scores}: K+1,
\qquad
\text{box outputs}: 4K,
\qquad
\text{mask logits}: K\times28\times28
$$

이다. Classification head의 $+1$은 background class다. 구현에 따라 box regression을 class-agnostic한 4개 값으로 만들거나 class/background channel convention을 다르게 둘 수 있지만, mask head는 background mask 없이 foreground class별 spatial output을 만든다.

### **9.1 Detection head와 mask head의 역할 분리**

Mask head는 원 image 전체 크기의 semantic map을 한 번 출력하지 않는다. 각 RoI 안에서 고정 크기 $m\times m$ binary mask를 만들고, 선택된 box 크기로 resize해 원 image 좌표에 배치한다.

Training에서는 ground-truth class에 해당하는 mask channel 하나를 선택해 pixel-wise sigmoid binary cross-entropy를 계산한다.

$$
\mathcal L_{\mathrm{mask}}
=
-\frac{1}{m^2}
\sum_{u,v}
\left[
m_{u,v}\log\sigma(\hat M^{(c)}_{u,v})
+(1-m_{u,v})
\log
\left(
1-\sigma(\hat M^{(c)}_{u,v})
\right)
\right]
$$

Class channel끼리 pixel마다 softmax 경쟁을 시키지 않는다. Classification head가 category를 정하고 mask head는 해당 instance의 foreground shape를 예측한다.

### **9.2 Per-RoI mask와 RoI Align**

같은 `dog` class의 box 두 개는 서로 다른 RoI feature와 서로 다른 binary target을 갖는다. 그래서 최종 output에서 두 dog가 분리된다.

RoI Pool의 quantization은 mask boundary를 feature와 어긋나게 만들 수 있다. RoI Align이 fractional coordinate와 bilinear interpolation을 사용하는 이유는 이 pixel-level alignment를 보존하기 위해서다. Mask branch를 하나 추가했다는 설명만으로는 Mask R-CNN의 정밀한 boundary가 충분히 설명되지 않는다.

같은 framework에서 mask 대신 keypoint heatmap을 추가하면 human pose estimation으로 확장할 수 있다. Detection으로 instance를 먼저 분리하고 RoI별 structured output을 붙이는 설계가 재사용되는 것이다.

## **10. Model representation의 시각화**

Detection과 segmentation은 prediction의 위치를 output으로 직접 학습한다. 분류 model에서는 spatial annotation 없이도 내부 feature나 gradient를 이용해 어느 pattern과 영역에 반응하는지 살펴볼 수 있다. 의료 영상처럼 양성·음성 label뿐 아니라 병변의 위치와 판단 근거가 실제 의사결정에 중요한 응용에서는 이 구분이 특히 크다.

### **10.1 Linear template과 first-layer filter**

[Linear classifier의 visual viewpoint](/posts/cs231n-lecture-2/#82-visual-viewpoint)에서는 class weight row를 image로 다시 펼쳐 class template처럼 볼 수 있었다. CNN의 첫 layer filter도 input channel이 RGB 세 개이므로 작은 color patch로 직접 표시할 수 있다.

![Linear classifier의 class template에서 AlexNet, ResNet과 DenseNet의 first-layer convolution filter 비교로 이어지는 model parameter 시각화]({{ '/assets/img/posts/cs231n-lecture-9/animations/linear-templates-first-layer-filters.gif' | relative_url }})

첫 layer에서는 edge orientation, color contrast와 low-frequency blob 같은 pattern이 보인다. Deeper filter는 input channel이 많아 weight tensor를 RGB image 한 장으로 직접 표현하기 어렵다. 이때는 filter 자체보다 어떤 input patch가 neuron을 크게 activate하는지 또는 input에 대한 gradient가 어디에 집중되는지를 본다.

### **10.2 Maximally activating patch와 guided backpropagation**

Maximally activating patch는 dataset을 model에 통과시켜 특정 neuron activation이 큰 image crop을 모은다. 이 방법은 neuron이 실제 data에서 어떤 visual pattern에 반응하는지 보여 준다.

![Intermediate neuron의 input gradient, guided-backprop ReLU gate와 maximally activating patch를 함께 비교하는 전체 과정]({{ '/assets/img/posts/cs231n-lecture-9/animations/guided-backprop.gif' | relative_url }})

Standard ReLU backward는 forward activation이 양수였던 위치에서만 upstream gradient를 통과시킨다. Guided backprop은 여기에 upstream gradient가 양수라는 조건도 추가한다.

$$
\frac{\partial L}{\partial x}
=
\mathbf 1[x>0]
\mathbf 1\left[
\frac{\partial L}{\partial y}>0
\right]
\frac{\partial L}{\partial y}
$$

결과 image가 선명하다는 사실과 explanation이 faithful하다는 사실은 다르다. Guided backprop은 negative gradient를 차단하는 visualization heuristic이다. Model parameter나 label을 randomize해도 비슷한 edge map이 남는지 확인하는 sanity check가 필요한 이유다.

## **11. Input-gradient saliency**

Training에서는 loss를 parameter로 미분한다. Input saliency에서는 target class의 unnormalized score $s_c$를 image pixel $X$로 미분한다.

$$
G
=
\frac{\partial s_c}{\partial X}
\in
\mathbb{R}^{3\times H\times W}
$$

RGB channel을 한 장으로 줄이는 대표적인 방법은 absolute gradient의 channel maximum이다.

$$
M_{h,w}
=
\max_{r\in\{R,G,B\}}
\left|
\frac{\partial s_c}
{\partial X_{r,h,w}}
\right|
$$

![Class score의 forward pass에서 input pixel gradient의 backward pass와 saliency map 사례로 이어지는 전체 과정]({{ '/assets/img/posts/cs231n-lecture-9/animations/saliency-map.gif' | relative_url }})

$M_{h,w}$가 크다는 것은 현재 image 근처에서 그 pixel을 조금 바꿀 때 class score가 빠르게 변한다는 뜻이다. 즉 **local first-order sensitivity**다.

이는 object segmentation mask가 아니며 model이 해당 pixel을 causal하게 사용했다는 증명도 아니다. Gradient saturation과 작은 perturbation에 민감하므로 saliency map은 정성적 진단 도구로 해석해야 한다.

---

## **12. CAM과 Grad-CAM**

Input saliency는 pixel까지 gradient를 내린다. CAM 계열은 convolutional feature map의 channel이 target class score에 얼마나 기여하는지 이용해 더 거친 spatial heatmap을 만든다.

### **12.1 Global average pooling 기반 CAM**

마지막 convolution feature를

$$
f
\in
\mathbb{R}^{H\times W\times K}
$$

라 하자. Global average pooling은 channel마다 scalar를 만든다.

$$
F_k
=
\frac{1}{HW}
\sum_{h,w}
f_{h,w,k}
$$

Linear classifier weight $w_{k,c}$를 사용하면 class score는

$$
\begin{aligned}
s_c
&=
\sum_k
w_{k,c}F_k\\
&=
\frac{1}{HW}
\sum_{h,w}
\sum_k
w_{k,c}f_{h,w,k}
\end{aligned}
$$

로 다시 쓸 수 있다. 따라서 class activation map은

$$
M_c(h,w)
=
\sum_k
w_{k,c}
f_{h,w,k}
$$

이다.

![마지막 convolution feature, global average pooling과 linear classifier weight에서 CAM 수식을 유도하고 class별 heatmap과 architecture 제약까지 확인하는 전체 과정]({{ '/assets/img/posts/cs231n-lecture-9/animations/class-activation-mapping.gif' | relative_url }})

CAM은 classifier weight를 spatial feature에 그대로 되돌려 쓸 수 있어 계산이 단순하다. 대신 마지막 convolution 뒤에 global average pooling과 linear classifier가 직접 이어지는 architecture가 필요하다. 중간에 복잡한 head가 있으면 이 정확한 유도가 성립하지 않는다.

### **12.2 Gradient-weighted channel importance**

Grad-CAM은 classifier weight 대신 target score가 선택한 feature map $A^k$에 주는 gradient를 channel importance로 사용한다.

$$
\alpha_k^c
=
\frac{1}{HW}
\sum_{h,w}
\frac{\partial s_c}
{\partial A_{h,w}^k}
$$

$$
M_c^{\mathrm{GradCAM}}
=
\operatorname{ReLU}
\left(
\sum_k
\alpha_k^c A^k
\right)
$$

![임의 convolution activation 선택, target class gradient, spatial average channel weight와 ReLU heatmap으로 완성되는 Grad-CAM 전체 유도]({{ '/assets/img/posts/cs231n-lecture-9/animations/grad-cam.gif' | relative_url }})

ReLU는 target class를 지지하는 positive evidence만 남긴다. Negative evidence도 중요하다면 ReLU 전 map이나 별도의 negative map을 봐야 한다.

얕은 layer는 spatial resolution이 높지만 class semantics가 약하고, 깊은 layer는 의미가 강하지만 feature map이 거칠다. Grad-CAM output도 선택한 layer resolution의 제한을 받아 원 image로 upsample한 coarse localization이다.

### **12.3 CNN heatmap과 ViT token map의 해석 범위**

| 방법 | 계산 대상 | Architecture 제약 | 대표 의미 |
|---|---|---|---|
| Input saliency | $\partial s_c/\partial X$ | Differentiable model | Pixel의 local sensitivity |
| CAM | Classifier weight와 마지막 conv feature | GAP + linear classifier | Class-weighted spatial activation |
| Grad-CAM | $\partial s_c/\partial A$와 activation | 선택 layer까지 gradient 가능 | Target을 지지하는 coarse region |
| Raw attention map | Query-key attention weight | Attention layer | Token 간 weight pattern |

![Image patch와 object part에 반응하는 Vision Transformer feature visualization]({{ '/assets/img/posts/cs231n-lecture-9/slides/p147-vit-feature-visualization.png' | relative_url }})

ViT의 patch token은 원래 patch layout에 맞춰 $H_p\times W_p$ grid로 다시 배열할 수 있다. 반면 raw attention은 head마다 $N\times N$ matrix이므로 class-token-to-patch처럼 특정 query row를 선택하거나 head·layer를 aggregate한 뒤에야 하나의 2D map으로 표시할 수 있다. 그래도 [attention map의 해석](/posts/cs231n-lecture-8/#21-attention-map의-soft-alignment)과 마찬가지로 raw weight만으로 causal explanation이 완성되지는 않는다. Value, residual path, MLP, 여러 layer와 head의 interaction이 최종 prediction에 함께 기여한다.

## **13. PyTorch를 이용한 spatial output 검산**

### **13.1 Dense logit과 transposed-convolution shape**

Segmentation loss는 class 축을 유지한 logit과 class 축이 없는 integer target을 받는다.

```python
import torch
import torch.nn.functional as F
from torch import nn

B, C, H, W = 2, 5, 128, 160

logits = torch.randn(B, C, H, W, requires_grad=True)
target = torch.randint(0, C, (B, H, W))

loss = F.cross_entropy(logits, target)
prediction = logits.argmax(dim=1)

print(loss.shape)        # torch.Size([])
print(prediction.shape)  # torch.Size([2, 128, 160])
```

`ConvTranspose2d`의 output size도 공식과 tensor를 함께 확인할 수 있다.

```python
x = torch.randn(2, 256, 32, 32)

up = nn.ConvTranspose2d(
    in_channels=256,
    out_channels=64,
    kernel_size=4,
    stride=2,
    padding=1,
)

y = up(x)
print(y.shape)  # torch.Size([2, 64, 64, 64])
```

각 spatial 축에

$$
(32-1)\times2
-2\times1
+(4-1)
+1
=64
$$

를 적용한 결과와 일치한다.

### **13.2 RoI Align과 NMS shape**

`roi_align`의 box 좌표가 원 image 기준이고 feature stride가 8이면 `spatial_scale=1/8`을 사용한다.

```python
from torchvision.ops import nms, roi_align

features = torch.randn(2, 256, 32, 32)

boxes = [
    torch.tensor([
        [16.0, 24.0, 144.0, 184.0],
        [80.0, 48.0, 216.0, 224.0],
    ]),
    torch.tensor([
        [32.0, 40.0, 176.0, 208.0],
    ]),
]

pooled = roi_align(
    features,
    boxes,
    output_size=(7, 7),
    spatial_scale=1 / 8,
    aligned=True,
)

print(pooled.shape)  # torch.Size([3, 256, 7, 7])
```

Batch 두 장의 RoI 수가 각각 2개와 1개이므로 첫 dimension은 $K=3$이다.

NMS는 box와 score를 받아 남길 index를 score 내림차순으로 반환한다.

```python
candidate_boxes = torch.tensor([
    [10.0, 10.0, 90.0, 90.0],
    [14.0, 12.0, 92.0, 88.0],
    [130.0, 20.0, 210.0, 100.0],
])
scores = torch.tensor([0.95, 0.88, 0.80])

keep = nms(
    candidate_boxes,
    scores,
    iou_threshold=0.5,
)

print(keep)  # tensor([0, 2])
```

첫 두 box는 많이 겹치므로 더 높은 score의 첫 box만 남고, 멀리 떨어진 세 번째 box는 유지된다.

## **14. 정리**

Semantic segmentation은 image classification을 pixel-wise classification으로 확장한다. Pixel 하나만으로는 context가 부족하고 patch마다 CNN을 반복하면 계산이 중복되므로 fully convolutional encoder-decoder가 image 전체의 dense logits를 만든다. Downsampling이 잃은 위치 정보는 fixed upsampling, max-unpooling, transposed convolution과 U-Net의 high-resolution skip feature로 보완한다.

Object detection은 output이 가변 길이 set이라는 새로운 문제를 만든다. R-CNN은 proposal마다 backbone을 반복했고 Fast R-CNN은 image feature를 공유했으며 Faster R-CNN은 proposal 생성까지 RPN으로 학습했다. RoI Pool은 fixed feature size를 만들지만 좌표를 quantize하고, RoI Align은 fractional coordinate의 bilinear sampling으로 pixel-level 정렬을 보존한다.

YOLO v1은 grid에서 box와 class를 dense prediction하는 single-stage 구조를 보여 준다. DETR는 learned object query와 one-to-one bipartite matching으로 detection을 set prediction으로 바꾼다. Query 수는 output capacity를 정하고 Hungarian matching은 duplicate prediction을 억제한다.

Mask R-CNN은 Faster R-CNN의 proposal마다 binary mask branch를 붙여 같은 class의 instance를 분리한다. Saliency, CAM, Grad-CAM은 model의 spatial response를 서로 다른 gradient와 feature level에서 보여 주지만 모두 자동으로 causal explanation이 되지는 않는다.

$$
\boxed{
\begin{aligned}
&\text{spatially shared features}\\
+{}&\text{structured output representation}\\
+{}&\text{explicit limits of attribution}\\
={}&\text{detection, segmentation, interpretation}
\end{aligned}
}
$$
