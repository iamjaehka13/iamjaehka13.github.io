## **0. 이 글의 목표**

[Lecture 7의 RNN](/posts/cs231n-lecture-7/)은 과거 입력을 고정 크기 hidden state에 압축하면서 sequence를 처리했다. 이 방식은 길이가 달라져도 같은 parameter를 사용할 수 있지만, encoder의 마지막 state 하나로 긴 입력 전체를 decoder에 전달하면 정보가 통과해야 하는 통로가 지나치게 좁아진다.

Lecture 8의 출발점은 이 병목을 없애는 것이다.

- Decoder가 매 출력 시점마다 입력 sequence의 다른 부분을 직접 참고하는 방법
- Query, key, value가 서로 다른 역할을 갖는 이유
- Self-attention에 위치 정보와 causal mask가 필요한 이유
- 여러 attention head를 병렬로 계산하고 다시 합치는 방법
- Attention을 Transformer block과 Vision Transformer로 확장하는 방법
- 긴 sequence에서 dense attention의 계산량과 메모리 비용

핵심은 **source 전체를 하나의 state에 미리 압축하는 대신, 현재 query에 필요한 value를 그때그때 가중합으로 읽는 것**이다. Transformer는 이 attention 연산을 vector 사이의 정보 교환 방식으로 사용하고, MLP를 각 vector 내부의 feature 변환으로 사용한다.

## **1. Fixed-size context vector의 병목**

Encoder-decoder RNN은 입력 $x_1,\ldots,x_T$를 순서대로 읽어 hidden state를 갱신한다.

$$
h_t=f_W(x_t,h_{t-1})
$$

가장 단순한 구조에서는 마지막 encoder state $h_T$를 context vector $c$로 사용하고, 이를 decoder의 초기 state $s_0$ 또는 각 decoder step의 조건으로 전달한다.

$$
c=h_T,
\qquad
s_t=g_U(y_{t-1},s_{t-1},c)
$$

Decoder는 `[START]` token에서 시작해 이전 출력 $y_{t-1}$을 다음 입력으로 사용하고 `[STOP]`이 나올 때까지 sequence를 생성한다.

![RNN encoder-decoder가 입력을 마지막 context vector에 압축하고 출력 sequence를 생성하면서 fixed-size bottleneck에 도달하는 전체 과정]({{ '/assets/img/posts/cs231n-lecture-8/animations/seq2seq-context-bottleneck.gif' | relative_url }})

문제는 모든 입력 정보가 $c$ 하나를 통과해야 한다는 점이다. 문장이 짧을 때는 이 압축이 가능할 수 있지만, 입력이 문단이나 문서처럼 길어져도 context dimension은 그대로다. Decoder의 첫 단어와 마지막 단어가 모두 같은 고정 vector에 의존하므로, 먼 위치의 세부 정보를 선택적으로 다시 읽을 방법이 없다.

여기서 말하는 병목은 단순히 hidden dimension이 작다는 뜻만은 아니다. **어떤 output을 생성하는 중인지와 관계없이 입력 전체를 동일한 요약으로 전달한다는 구조적 제약**이다. 출력 단어마다 필요한 입력 정보가 다른 번역 task와 잘 맞지 않는다.

Decoder의 "초기화"도 두 의미를 구분해야 한다. Model parameter의 random initialization과 sequence 시작 시점의 $s_0$ 설정은 다른 문제다. $s_0$는 마지막 encoder state, 그 state의 learned projection, 또는 zero vector가 될 수 있으며, 중요한 것은 학습과 inference에서 같은 규칙을 사용하는 것이다.

## **2. Attention을 통한 동적 context vector**

Attention은 고정 context $c$를 모든 시점에 재사용하지 않는다. Decoder의 이전 state $s_{t-1}$와 각 encoder state $h_i$ 사이의 관련도를 계산하고, 현재 출력 시점 $t$에 맞는 context $c_t$를 새로 만든다.

첫 단계는 scalar alignment score다.

$$
e_{t,i}=f_{\mathrm{att}}(s_{t-1},h_i)
$$

$e_{t,i}$가 클수록 현재 decoder state가 입력 위치 $i$를 더 관련 있다고 평가한다. Additive attention의 대표적인 형태는 다음과 같다.

$$
e_{t,i}
=
v^{\mathsf T}
\tanh
\left(
W_s s_{t-1}+W_h h_i
\right)
$$

단순히 두 vector를 concatenate한 뒤 scalar affine layer 하나만 적용하면 query 쪽 항이 모든 key logit에 같은 상수로 더해져 softmax에서 상쇄될 수 있다. Nonlinearity를 포함한 score function은 두 vector의 상호작용을 표현한다.

두 번째 단계는 encoder 위치 전체에 대한 softmax다.

$$
a_{t,i}
=
\frac{\exp(e_{t,i})}
{\sum_{j=1}^{T}\exp(e_{t,j})}
$$

$$
0<a_{t,i}<1,
\qquad
\sum_{i=1}^{T}a_{t,i}=1
$$

세 번째 단계는 encoder state의 weighted sum이다.

$$
c_t
=
\sum_{i=1}^{T}a_{t,i}h_i
$$

마지막으로 decoder는 고정된 $c$ 대신 현재 시점의 $c_t$를 사용한다.

$$
s_t=g_U(y_{t-1},s_{t-1},c_t)
$$

![Encoder hidden state와 decoder state의 alignment score, softmax weight, weighted context와 decoder update가 반복되는 attention의 전체 유도]({{ '/assets/img/posts/cs231n-lecture-8/animations/rnn-attention-derivation.gif' | relative_url }})

이제 decoder는 각 output마다 source 전체를 다시 보고 다른 요약을 만들 수 있다. `vediamo`를 생성할 때와 `cielo`를 생성할 때 사용하는 attention weight가 달라지므로, 입력 전체가 하나의 고정 vector를 통과하지 않는다.

별도의 word alignment label도 필요하지 않다. 번역 token에 대한 cross-entropy loss를 줄이는 과정에서 alignment score function, encoder, decoder를 end-to-end로 함께 학습한다. Backpropagation은 context weighted sum을 통해 attention weight와 encoder state 양쪽으로 전달된다.

### **2.1 Attention map의 soft alignment**

Attention weight $a_{t,i}$를 source position과 target position의 행렬로 그리면 model이 각 target을 만들 때 어느 source 위치에 큰 weight를 두었는지 볼 수 있다.

![영어-프랑스어 번역에서 대각선, 역순 대응과 여러 단어 블록으로 나타나는 attention map의 전체 해석 과정]({{ '/assets/img/posts/cs231n-lecture-8/animations/translation-attention-map.gif' | relative_url }})

- 대각선 방향의 밝은 pattern은 source와 target의 순서가 비슷한 일대일 대응
- 반대 방향이나 휘어진 pattern은 언어 사이의 word order 변화
- 여러 칸에 퍼진 block은 여러 source word가 하나의 target 표현에 함께 기여하는 관계

이 map은 별도의 정렬 supervision 없이 학습된 **soft alignment의 단서**다. 다만 밝은 attention cell을 곧바로 model prediction의 완전한 causal explanation으로 해석하면 안 된다. Value vector의 내용, 이후 layer의 residual path와 MLP도 최종 prediction에 영향을 준다.

## **3. Query·Key·Value를 이용한 attention의 일반화**

RNN 번역에서 attention만 떼어 내면 더 일반적인 연산이 보인다.

- **Query $q$**: 지금 어떤 정보를 찾는지 나타내는 vector
- **Data vectors $X_i$**: 읽을 수 있는 정보의 집합
- **Score $e_i$**: query와 각 data vector의 관련도
- **Weight $a_i$**: key 전체에 대해 정규화한 관련도
- **Output $y$**: query에 맞춰 만든 data vector의 weighted summary

$$
e_i=f_{\mathrm{att}}(q,X_i)
$$

$$
a=\operatorname{softmax}(e)
$$

$$
y=\sum_i a_iX_i
$$

![RNN attention에서 query와 data vector의 유사도, softmax와 weighted output으로 일반화되는 attention layer]({{ '/assets/img/posts/cs231n-lecture-8/animations/generic-attention-layer.gif' | relative_url }})

Attention layer는 query가 어디에서 왔는지 알 필요가 없다. Query는 decoder hidden state, image feature, learned token 또는 다른 modality의 representation일 수 있다. 연산이 하는 일은 query마다 data 집합에서 다른 custom summary를 만드는 것이다.

### **3.1 Scaled dot-product similarity**

Learnable score network 대신 query와 key의 dot product를 사용할 수 있다.

$$
e_i=q^{\mathsf T}k_i
$$

Dimension $d_k$가 커질수록 dot product의 분산도 커진다. 각 component가 평균 0, 분산 1에 가깝고 서로 독립이라고 단순화하면

$$
\operatorname{Var}
\left(
q^{\mathsf T}k_i
\right)
=d_k
$$

가 된다. 너무 큰 logit은 softmax를 거의 one-hot으로 포화시키고 작은 probability 쪽 gradient를 약하게 만든다. 따라서 $\sqrt{d_k}$로 나누어 logit scale을 안정화한다.

$$
e_i
=
\frac{q^{\mathsf T}k_i}{\sqrt{d_k}}
$$

이는 [softmax의 수치 안정성](/posts/cs231n-lecture-2/#103-수치-안정성)을 위한 max subtraction과 목적이 다르다. Max subtraction은 overflow를 막고, $1/\sqrt{d_k}$ scaling은 dimension에 따라 logit 분산이 커지는 현상을 조절한다.

### **3.2 Cross-attention의 matrix 계산**

Query가 $N_q$개, source vector가 $N_x$개라고 하자.

$$
Q\in\mathbb{R}^{N_q\times d_q},
\qquad
X\in\mathbb{R}^{N_x\times d_x}
$$

Source vector를 key와 value로 각각 projection한다.

$$
K=XW_K
\in\mathbb{R}^{N_x\times d_k}
$$

$$
V=XW_V
\in\mathbb{R}^{N_x\times d_v}
$$

Query도 key와 dot product가 가능하도록 projection한다.

$$
\widetilde Q=QW_Q
\in\mathbb{R}^{N_q\times d_k}
$$

모든 query-key pair의 score를 하나의 matrix multiplication으로 계산한다.

$$
E
=
\frac{\widetilde QK^{\mathsf T}}{\sqrt{d_k}}
\in
\mathbb{R}^{N_q\times N_x}
$$

각 row는 query 하나, 각 column은 source key 하나에 해당한다. Softmax는 **각 query마다 key 축**으로 수행한다.

$$
A
=
\operatorname{softmax}_{\text{keys}}(E)
\in
\mathbb{R}^{N_q\times N_x}
$$

$$
Y=AV
\in
\mathbb{R}^{N_q\times d_v}
$$

![Dot product scaling, 여러 query의 matrix 계산, key와 value 분리에서 cross-attention 완성까지 이어지는 전체 과정]({{ '/assets/img/posts/cs231n-lecture-8/animations/scaled-dot-product-cross-attention.gif' | relative_url }})

Key와 value를 분리하는 이유는 **무엇과 match할지**와 **실제로 어떤 정보를 돌려줄지**를 분리하기 위해서다. 검색으로 비유하면 query는 검색어, key는 검색 index, value는 검색 결과의 내용이다. 이 역할은 사람이 dimension별 의미를 지정하는 것이 아니라 학습된 projection $W_Q,W_K,W_V$가 만든다.

Query와 source가 서로 다른 집합에서 오면 cross-attention이다. 번역에서는 decoder state가 query이고 encoder states가 key와 value다. Vision-language model에서는 word token이 query이고 image region이 key와 value가 될 수 있다.

## **4. Self-attention과 입력 집합 내부의 정보 교환**

Self-attention은 query, key, value를 모두 같은 입력 $X$에서 만든다.

$$
\begin{aligned}
Q&=XW_Q\\
K&=XW_K\\
V&=XW_V
\end{aligned}
$$

$$
\operatorname{Attention}(X)
=
\operatorname{softmax}_{\text{keys}}
\left(
\frac{QK^{\mathsf T}}{\sqrt{d_k}}
\right)V
$$

Input vector $x_i$마다 query $q_i$가 생기므로 output $y_i$도 하나씩 나온다. 각 $y_i$는 input 전체의 value를 서로 다른 attention weight로 섞은 결과다.

![하나의 입력 X에서 Q, K, V를 만들고 모든 input pair의 similarity와 weighted output을 계산하는 self-attention의 전체 흐름]({{ '/assets/img/posts/cs231n-lecture-8/animations/self-attention-qkv-flow.gif' | relative_url }})

Q, K, V projection은 보통 하나의 큰 matrix multiplication으로 묶어 계산할 수 있다.

$$
[Q\;K\;V]
=
X[W_Q\;W_K\;W_V]
$$

구현에서는 projection 결과를 마지막 dimension에서 세 부분으로 split한다. 세 개의 작은 matrix multiplication보다 accelerator가 처리하기 좋은 큰 matrix multiplication 하나를 사용하는 방식이다.

### **4.1 Permutation equivariance**

위치 정보를 주지 않은 self-attention은 입력 순서를 자체적으로 알지 못한다. 입력 row를 permutation matrix $P$로 재배열하면 output도 같은 방식으로 재배열된다.

$$
F(PX)=PF(X)
$$

이는 학습 중 우연히 생기는 성질이 아니라 weight를 고정한 forward 연산의 대칭성이다. 모든 input pair를 계산하지만, `첫 번째 token`과 `세 번째 token`이라는 위치 개념은 $X$ 자체에 없다.

### **4.2 Positional encoding을 통한 순서 정보**

Sequence order가 필요한 task에서는 token representation에 position vector를 주입한다.

$$
z_i=x_i+p_i
$$

$p_i$는 sinusoidal function으로 고정할 수도 있고 learned embedding으로 둘 수도 있다. 일반적인 구현에서는 token과 같은 dimension의 position vector를 더하지만, concatenate한 뒤 projection하는 다른 설계도 가능하다.

중요한 점은 attention matrix가 위치를 자동으로 발견하는 것이 아니라, **input representation에 위치를 구분할 수 있는 신호를 넣어 permutation symmetry를 깨는 것**이다.

### **4.3 Causal mask와 미래 정보 차단**

Autoregressive language model은 위치 $i$에서 미래 token $j>i$를 볼 수 없어야 한다. Softmax 이전 score에 $-\infty$를 넣으면 해당 위치의 probability가 0이 된다.

$$
M_{ij}
=
\begin{cases}
0,&j\le i\\
-\infty,&j>i
\end{cases}
$$

$$
A
=
\operatorname{softmax}_{\text{keys}}
\left(
\frac{QK^{\mathsf T}}{\sqrt{d_k}}+M
\right)
$$

![입력 permutation에 대한 self-attention의 equivariance, positional encoding과 causal mask로 이어지는 전체 과정]({{ '/assets/img/posts/cs231n-lecture-8/animations/permutation-position-causal-mask.gif' | relative_url }})

Mask를 softmax 이후에 단순 곱하면 row sum이 1이 아니게 되므로 다시 정규화해야 한다. Logit 단계의 $-\infty$ mask가 더 직접적인 이유다.

Training에서는 정답 sequence 전체를 한 번에 입력하더라도 triangular mask가 미래 token을 차단하므로 모든 position의 next-token loss를 병렬 계산할 수 있다. 반면 inference에서는 다음 token이 아직 존재하지 않기 때문에 한 token씩 순차 생성해야 한다. **Causal mask는 training의 정보 누출을 막지만 autoregressive generation의 순차성까지 없애지는 않는다.**

## **5. Multi-head self-attention**

Single-head attention은 하나의 projection space에서 similarity와 value mixing을 계산한다. Multi-head attention은 서로 다른 $W_Q,W_K,W_V$를 가진 여러 attention head를 병렬로 사용한다.

Model dimension을 $D$, head 수를 $H$, head dimension을 $d_h$라 하면 보통

$$
D=H d_h
$$

로 둔다. Projection 결과를 다음 shape으로 reshape한다.

$$
Q,K,V
\in
\mathbb{R}^{H\times N\times d_h}
$$

각 head에서

$$
A^{(h)}
=
\operatorname{softmax}_{\text{keys}}
\left(
\frac{Q^{(h)}K^{(h)\mathsf T}}{\sqrt{d_h}}
\right)
$$

$$
Y^{(h)}=A^{(h)}V^{(h)}
$$

를 계산한다. Head output을 concatenate한 뒤 output projection으로 섞는다.

$$
Y
=
\operatorname{Concat}
\left(
Y^{(1)},\ldots,Y^{(H)}
\right)
W_O
$$

![여러 독립 self-attention head의 병렬 계산, head output stacking과 output projection의 전체 과정]({{ '/assets/img/posts/cs231n-lecture-8/animations/multihead-self-attention.gif' | relative_url }})

각 head가 서로 다른 관계를 학습할 수는 있지만, head마다 사람이 이름 붙일 수 있는 개념 하나가 반드시 대응되는 것은 아니다. 여러 head가 비슷한 pattern을 학습하거나 한 관계가 여러 head에 분산될 수도 있다.

또한 head 수가 $H$라고 parameter와 FLOPs가 자동으로 $H$배가 되는 것도 아니다. 전체 model dimension $D$를 고정하고 $d_h=D/H$로 나누는 표준 설계에서는 fused projection의 전체 width가 그대로다. Head 수는 계산을 partition하는 방식과 표현 공간의 분해를 바꾼다.

### **5.1 네 번의 핵심 matrix multiplication**

Fused multi-head self-attention의 큰 연산은 네 단계로 정리할 수 있다.

1. **QKV projection**

   $$
   [N\times D][D\times3D]
   \rightarrow[N\times3D]
   $$

2. **QK similarity**

   $$
   \begin{aligned}
   &[H\times N\times d_h]\\
   {}\times{}&[H\times d_h\times N]\\
   {}\rightarrow{}&[H\times N\times N]
   \end{aligned}
   $$

3. **Value weighting**

   $$
   \begin{aligned}
   &[H\times N\times N]\\
   {}\times{}&[H\times N\times d_h]\\
   {}\rightarrow{}&[H\times N\times d_h]
   \end{aligned}
   $$

4. **Output projection**

   $$
   [N\times D][D\times D]
   \rightarrow[N\times D]
   $$

### **5.2 Dense attention의 quadratic cost와 FlashAttention**

$QK^{\mathsf T}$는 모든 query-key pair를 계산하므로 sequence length $N$에 대해 $O(N^2D)$의 arithmetic cost가 필요하다. Attention weight를 명시적으로 저장하면 shape이 $H\times N\times N$이므로 memory도 $O(HN^2)$다.

![QKV projection, QK similarity, value weighting, output projection과 N제곱 비용에서 FlashAttention까지 이어지는 전체 전개]({{ '/assets/img/posts/cs231n-lecture-8/animations/attention-matmuls-complexity-flash.gif' | relative_url }})

FlashAttention은 $N\times N$ attention matrix 전체를 GPU HBM에 materialize하지 않는다. Q, K, V를 tile로 나누고 on-chip SRAM에서 softmax 통계와 value accumulation을 함께 갱신해 HBM read·write를 줄인다.

중요한 구분은 다음과 같다.

- 수학적으로 계산하는 dense pair 수: 여전히 $O(N^2)$
- Naive implementation의 attention-matrix storage: $O(N^2)$
- FlashAttention의 auxiliary HBM memory: 전체 matrix 저장을 피해 sequence length에 대해 선형 수준

즉 FlashAttention은 approximation이 아니라 exact attention algorithm이며, dense attention의 산술적 quadratic complexity를 linear로 바꾸는 방법은 아니다. 긴 sequence를 실제 hardware에서 훨씬 효율적으로 처리하도록 memory traffic을 줄이는 방법이다.

## **6. RNN·convolution·self-attention의 계산 특성 비교**

![RNN, convolution과 self-attention의 순서 구조, receptive field, 병렬성, 계산량을 비교하는 전체 슬라이드 흐름]({{ '/assets/img/posts/cs231n-lecture-8/animations/sequence-operator-comparison.gif' | relative_url }})

| 연산 | 한 layer의 정보 범위 | 시간축 병렬성 | 길이 $N$에 대한 핵심 비용 | 구조적 성질 |
|---|---|---:|---:|---|
| RNN | 이전 state를 통한 누적 정보 | 낮음 | $O(N)$ | 순서가 update 자체에 포함 |
| Convolution | kernel 크기의 local neighborhood | 높음 | 대체로 $O(N)$ | locality와 grid 구조 |
| Self-attention | 모든 pair의 global interaction | 높음 | $O(N^2)$ | 위치 신호가 없으면 set operator |

RNN은 sequence가 길어도 step당 state update는 일정하지만 $h_t$를 계산하기 전에 $h_{t-1}$가 필요하다. Convolution은 병렬화가 쉽지만 한 layer의 receptive field가 local하므로 먼 위치의 정보가 만나려면 layer를 쌓거나 kernel을 키워야 한다. Self-attention은 한 layer에서 모든 vector가 직접 상호작용하고 matrix multiplication으로 병렬화할 수 있지만, 그 대가가 quadratic pairwise cost다.

"Attention에는 bottleneck이 없다"는 말은 고정 context vector 하나로 source를 압축하지 않는다는 뜻이다. 긴 입력을 무료로 처리한다는 뜻은 아니다. 긴 context에서는 attention score 계산, KV cache, memory bandwidth와 latency가 새로운 병목이 된다.

## **7. Transformer block의 구성**

Transformer는 attention layer 하나의 다른 이름이 아니다. 기본 block은 두 종류의 연산을 residual path와 normalization으로 묶는다.

1. **Multi-head self-attention**: vector 사이의 정보 교환
2. **Position-wise MLP**: 각 vector 내부의 feature 변환

원래 Transformer의 post-norm 형태를 간단히 쓰면 다음과 같다.

$$
u
=
\operatorname{LayerNorm}
\left(
x+\operatorname{MHA}(x)
\right)
$$

$$
y
=
\operatorname{LayerNorm}
\left(
u+\operatorname{MLP}(u)
\right)
$$

![입력 vector에서 self-attention, residual, LayerNorm, position-wise MLP와 두 번째 residual을 조립하는 Transformer block의 전체 과정]({{ '/assets/img/posts/cs231n-lecture-8/animations/transformer-block-assembly.gif' | relative_url }})

Self-attention만 vector 사이를 섞는다. LayerNorm과 MLP는 token별로 독립적으로 적용된다. 고전적인 feed-forward network는 dimension을 $D\rightarrow4D\rightarrow D$로 확장했다가 다시 줄이는 두 개의 linear layer와 activation으로 구성된다.

$$
\operatorname{MLP}(x)
=
W_2\sigma(W_1x+b_1)+b_2
$$

Residual connection은 attention이나 MLP가 만든 변화량을 원래 representation에 더한다. 이 구조는 [Lecture 6의 ResNet](/posts/cs231n-lecture-6/#6-resnet과-깊은-network의-optimization-degradation)과 같은 additive shortcut 관점을 공유한다. LayerNorm의 통계 축은 [Lecture 6의 normalization 정리](/posts/cs231n-lecture-6/#2-normalization별-통계-계산-축의-차이)처럼 각 token vector의 feature dimension이다.

### **7.1 Transformer block의 반복 적층**

Transformer model은 같은 구조의 block을 여러 층 쌓아 만든다. Parameter를 layer 사이에 공유해야 하는 것은 아니며, 각 block은 자기 attention projection과 MLP weight를 가진다.

![완성된 Transformer block에서 여러 block의 반복 적층과 model 규모 확장으로 이어지는 과정]({{ '/assets/img/posts/cs231n-lecture-8/animations/transformer-scale.gif' | relative_url }})

한 block의 attention에서 global information exchange가 일어나고 MLP에서 feature가 재조합된다. 다음 block은 그 결과를 다시 query, key, value로 projection한다. 깊이가 늘수록 단순한 pairwise mixing을 여러 단계의 관계 추론으로 조합할 수 있지만 activation memory와 training cost도 함께 증가한다.

## **8. Language model을 위한 causal Transformer**

Language model은 token index를 embedding vector로 바꾸고 positional information을 더한 뒤, causal self-attention을 사용하는 Transformer block에 넣는다.

Vocabulary 크기를 $V$, model dimension을 $D$라 하면 embedding table은 보통

$$
E\in\mathbb{R}^{V\times D}
$$

이고 token index마다 $D$-dimensional vector를 lookup한다. 마지막에는 각 position의 hidden vector를 vocabulary logit으로 projection한다.

$$
Z=HW_{\mathrm{vocab}}
\in
\mathbb{R}^{N\times V}
$$

![Token embedding, positional information, masked Transformer block, vocabulary projection과 next-token loss로 이어지는 language model pipeline]({{ '/assets/img/posts/cs231n-lecture-8/animations/transformer-language-model.gif' | relative_url }})

Training input이 `attention is very cool`이라면 각 position의 target은 한 칸 뒤 token이다. 모든 target은 이미 알려져 있으므로 한 번의 forward에서 모든 position의 loss를 계산할 수 있다. Causal mask가 position $i$에서 $i+1$ 이후의 token을 가리기 때문에 정답 누출은 없다.

Inference에서는 첫 prefix로 한 token의 distribution을 계산하고, 선택한 token을 sequence에 붙인 뒤 다음 position을 다시 계산한다. KV cache를 사용하면 이전 token의 key와 value를 재사용할 수 있지만 새 token은 여전히 순차적으로 생성한다. Next-token supervision의 기본 구조는 [Lecture 7의 character-level language model](/posts/cs231n-lecture-7/#6-character-level-language-model)과 같고, recurrent state 대신 causal attention이 context를 읽는다는 점이 다르다.

## **9. Vision Transformer의 patch tokenization**

Self-attention은 본질적으로 vector 집합을 받으므로 image도 vector sequence로 바꾸면 같은 Transformer를 적용할 수 있다. $H\times W\times C$ image를 $P\times P$ patch로 나누면 token 수는

$$
N
=
\frac{H}{P}
\frac{W}{P}
$$

가 된다. Patch 하나를 flatten하면 dimension은 $P^2C$이고, linear projection을 통해 model dimension $D$로 바꾼다.

$$
x_i
=
\operatorname{vec}(\text{patch}_i)W_E+b_E
\in
\mathbb{R}^{D}
$$

![입력 image의 patch 분할, flatten과 linear projection, 2D positional encoding, global self-attention과 pooling의 Vision Transformer 전체 과정]({{ '/assets/img/posts/cs231n-lecture-8/animations/vision-transformer-pipeline.gif' | relative_url }})

### **9.1 Patch embedding과 convolution의 동치 관계**

모든 non-overlapping patch에 같은 linear projection을 적용하는 연산은 다음 convolution과 계산적으로 같다.

```python
from torch import nn

patch_embed = nn.Conv2d(
    in_channels=3,
    out_channels=embed_dim,
    kernel_size=patch_size,
    stride=patch_size,
)
```

Kernel이 patch 전체를 보고 stride도 patch 크기와 같으므로 overlap 없이 각 patch를 $D$개 channel로 projection한다. 이는 [Lecture 5의 convolution](/posts/cs231n-lecture-5/#3-convolution-layer의-계산-원리)을 patch tokenization 관점으로 읽은 것이다.

### **9.2 2D position과 classification readout**

Image patch는 text처럼 causal order를 갖지 않으므로 future mask를 사용하지 않는다. 모든 patch가 다른 모든 patch를 볼 수 있다. 대신 patch의 2D 위치를 구분하는 positional embedding이 필요하다.

Transformer는 patch마다 output vector를 만든다. Image classification에서는 learned class token을 readout으로 사용할 수도 있고, patch output을 average pooling한 뒤 linear classifier를 적용할 수도 있다.

Patch size는 연산량에 직접 영향을 준다. $P$를 절반으로 줄이면 세로와 가로 patch 수가 각각 2배가 되어 token 수 $N$이 4배가 된다. Dense attention matrix의 원소 수 $N^2$은 16배가 된다. 작은 patch는 더 세밀한 spatial resolution을 제공하지만 attention cost를 빠르게 증가시킨다.

## **10. 현대 Transformer block의 변화**

기본 구조는 유지되지만 normalization 위치, normalization 종류, MLP와 conditional computation에는 여러 변화가 사용된다.

![Post-Norm에서 Pre-Norm, RMSNorm, SwiGLU와 Mixture of Experts로 이어지는 현대 Transformer block 변화의 전체 과정]({{ '/assets/img/posts/cs231n-lecture-8/animations/modern-transformer-tweaks.gif' | relative_url }})

### **10.1 Pre-Norm과 residual identity path**

Post-Norm은 sublayer와 residual을 더한 뒤 normalization을 적용한다.

$$
y=\operatorname{Norm}(x+F(x))
$$

Pre-Norm은 normalization을 sublayer 안쪽으로 옮긴다.

$$
y=x+F(\operatorname{Norm}(x))
$$

두 번째 형태에서는 residual branch의 $x$가 normalization을 거치지 않고 그대로 다음 layer로 전달된다. 깊은 Transformer에서 identity와 gradient path를 보존하기 쉬워 training stability에 유리하다. 다만 Pre-Norm과 Post-Norm은 최종 representation scale과 학습 dynamics가 다르므로 단순히 같은 식의 순서만 바꾼 것으로 보면 안 된다.

### **10.2 RMSNorm의 scale normalization**

LayerNorm은 평균을 빼고 variance로 나눈다. RMSNorm은 mean centering을 생략하고 root mean square로 scale만 조절한다.

$$
\operatorname{RMS}(x)
=
\sqrt{
\epsilon
+
\frac{1}{D}
\sum_{i=1}^{D}x_i^2
}
$$

$$
y_i
=
\gamma_i
\frac{x_i}{\operatorname{RMS}(x)}
$$

RMSNorm도 token별 feature dimension을 정규화하며 learned scale $\gamma$를 가진다. Mean subtraction과 shift invariance는 없지만 계산이 더 단순하다.

### **10.3 SwiGLU feed-forward layer**

고전적인 Transformer MLP는 하나의 expanded branch에 activation을 적용한다.

$$
Y=\sigma(XW_1)W_2
$$

SwiGLU는 두 개의 projection branch 중 하나를 SiLU/Swish gate로 사용한다.

$$
Y
=
\left(
\operatorname{SiLU}(XW_1)
\odot
XW_2
\right)W_3
$$

Classic $D\rightarrow4D\rightarrow D$ MLP와 parameter 수를 비슷하게 맞추려면 hidden width를 대략 $8D/3$로 둘 수 있다. Element-wise product가 input-dependent gate 역할을 하면서 두 feature projection을 결합한다.

### **10.4 Mixture of Experts의 sparse routing**

Mixture of Experts는 각 Transformer block의 MLP를 $E$개의 expert로 확장하고, token마다 router가 일부 $A<E$개의 expert만 선택한다.

$$
y_i
=
\sum_{e\in\operatorname{TopA}(r(x_i))}
g_{i,e}F_e(x_i)
$$

전체 expert parameter는 크게 늘릴 수 있지만 token 하나가 사용하는 active expert 수는 제한되므로 compute 증가는 parameter 증가보다 작다. Dense MLP와 다른 점은 모든 token이 같은 weight를 통과하지 않는다는 점이다.

그 대신 router가 일부 expert에 token을 몰아주는 load imbalance, device 사이 token dispatch와 communication overhead, expert capacity 관리가 새로운 문제다. MoE의 장점은 parameter가 많다는 사실 자체가 아니라 **조건부로 일부 parameter만 활성화하는 sparse computation**에 있다.

## **11. PyTorch를 이용한 attention shape·mask 검산**

PyTorch의 scaled dot-product attention은 query, key, value의 마지막 두 dimension을 sequence와 head dimension으로 사용한다.

```python
import torch
import torch.nn.functional as F

batch_size = 2
num_heads = 8
seq_len = 16
head_dim = 64

q = torch.randn(
    batch_size,
    num_heads,
    seq_len,
    head_dim,
)
k = torch.randn_like(q)
v = torch.randn_like(q)

y = F.scaled_dot_product_attention(
    q,
    k,
    v,
    is_causal=True,
)

print(y.shape)  # (2, 8, 16, 64)
```

같은 causal attention을 직접 계산하면 mask가 어느 축에 적용되는지 확인할 수 있다.

```python
scale = head_dim ** -0.5
scores = torch.matmul(
    q,
    k.transpose(-2, -1),
) * scale

future = torch.ones(
    seq_len,
    seq_len,
    dtype=torch.bool,
).triu(diagonal=1)

scores.masked_fill_(
    future,
    -torch.inf,
)

weights = torch.softmax(
    scores,
    dim=-1,
)
y_manual = weights @ v

torch.testing.assert_close(
    y,
    y_manual,
)
```

`scores`의 shape은 `(batch, heads, query, key)`다. 따라서 `dim=-1` softmax는 각 query마다 key 전체를 정규화한다. Row와 column을 어떻게 그렸는지에 따라 그림의 방향은 달라질 수 있으므로 구현에서는 dimension의 의미를 먼저 확인해야 한다.

`nn.MultiheadAttention`은 projection, head split, attention과 output projection을 묶는다.

```python
from torch import nn

model_dim = 512
num_heads = 8

mha = nn.MultiheadAttention(
    embed_dim=model_dim,
    num_heads=num_heads,
    batch_first=True,
)

x = torch.randn(2, 16, model_dim)

output, _ = mha(
    x,
    x,
    x,
    need_weights=False,
)

print(output.shape)  # (2, 16, 512)
```

Self-attention은 세 input이 모두 `x`이고, cross-attention에서는 첫 번째 input인 query와 key/value input이 서로 다르다. 실제 training에서는 framework가 제공하는 fused scaled-dot-product attention path를 활용할 수 있도록 attention weight가 필요하지 않을 때 `need_weights=False`를 사용하는 편이 유리하다.

## **12. 정리**

Encoder-decoder RNN은 입력 전체를 마지막 hidden state 하나에 압축하기 때문에 긴 sequence에서 fixed-size communication bottleneck을 만든다. Attention은 decoder의 현재 query와 모든 encoder state의 alignment를 계산하고, 시점마다 다른 weighted context를 만들어 이 병목을 완화한다.

Query, key, value 관점에서는 attention을 특정 architecture와 분리할 수 있다. Query와 source가 다르면 cross-attention이고, 같은 $X$에서 Q, K, V를 만들면 self-attention이다. Scaled dot product는 dimension에 따른 logit scale을 조절하고, 모든 pair를 matrix multiplication으로 계산한다.

Self-attention은 위치 정보가 없으면 permutation equivariant하므로 positional encoding이 필요하다. Autoregressive model에서는 미래 score를 $-\infty$로 만드는 causal mask가 정보 누출을 막는다. Multi-head attention은 여러 projection space의 결과를 concatenate하고 output projection으로 다시 결합한다.

Transformer block은 attention만으로 구성되지 않는다. Self-attention이 token 사이 정보를 섞고, position-wise MLP가 token 내부 feature를 바꾸며, residual connection과 normalization이 깊은 stack의 학습 경로를 만든다. Language model은 causal mask를 사용하고, Vision Transformer는 image patch를 token으로 바꿔 global self-attention을 적용한다.

Dense attention은 한 layer에서 global interaction을 얻는 대신 $O(N^2)$ pairwise cost를 지불한다. FlashAttention은 전체 attention matrix를 HBM에 저장하지 않는 exact tiled algorithm으로 memory traffic을 줄이지만 arithmetic pair 수를 바꾸지는 않는다. Pre-Norm, RMSNorm, SwiGLU와 MoE는 이 기본 block의 학습 안정성, feature transformation과 conditional capacity를 확장한다.

$$
\boxed{
\begin{aligned}
S&=\frac{QK^{\mathsf T}}{\sqrt{d_k}}+M\\
A&=\operatorname{softmax}_{\text{keys}}(S)\\
Y&=AV
\end{aligned}
}
$$
