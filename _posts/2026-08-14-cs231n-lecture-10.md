## **0. 이 글의 목표**

[Lecture 9의 detection·segmentation과 model interpretation](/posts/cs231n-lecture-9/)까지는 한 장의 image 안에서 **무엇이 어디에 있는지**를 다뤘다. Video에서는 여기에 시간이 추가된다. 정지 화면만으로도 보이는 사람과 물체가 있지만, 달리기와 걷기, 앉기와 일어나기, 문을 여는 동작과 닫는 동작은 frame의 **순서와 변화**까지 봐야 구별할 수 있다.

이번 글의 핵심 질문은 다음과 같다.

- 긴 video를 GPU가 처리할 수 있는 clip tensor로 바꾸는 방법
- Single-frame model을 먼저 확인해야 하는 이유
- Late fusion, early fusion, 3D CNN이 시간을 합치는 위치의 차이
- 같은 motion detector를 여러 시점에 재사용하는 temporal weight sharing
- RGB appearance와 optical flow motion을 분리하는 two-stream 구조
- 긴 시간 관계를 다루는 recurrence와 global self-attention의 차이
- ImageNet의 2D weight를 3D model로 옮기는 I3D initialization
- Clip classification을 localization·audio-visual·long-video understanding으로 확장하는 방법

핵심은 **video를 image 여러 장의 묶음으로만 보는 것이 아니라, 시간축을 보존한 채 어느 범위의 변화를 언제 결합할지 설계하는 것**이다.

## **1. Image tensor에서 video tensor로의 확장**

RGB image 한 장은 $C\times H\times W$ tensor다. 여기에 $T$개의 frame을 시간 순서대로 쌓으면 video clip은 다음과 같은 4D tensor가 된다.

$$
X\in\mathbb{R}^{C\times T\times H\times W}
$$

PyTorch의 `Conv3d`는 batch까지 포함한 다음 순서를 기본으로 사용한다.

$$
X\in\mathbb{R}^{B\times C\times T\times H\times W}
$$

![시간 순서의 image frame을 4D video tensor로 쌓은 구조]({{ '/assets/img/posts/cs231n-lecture-10/slides/p7-video-tensor.png' | relative_url }})

시간축은 단순히 데이터 크기만 하나 늘리는 축이 아니다. $t$번째 frame과 $t+1$번째 frame의 차이, 변화의 방향, 변화가 지속되는 속도를 담는다. 같은 frame 집합도 시간 순서를 뒤집으면 서로 다른 action을 나타낼 수 있다.

무압축 RGB video의 byte 수는 대략 다음과 같다.

$$
\text{bytes}
=
F\cdot S\cdot H\cdot W\cdot 3
$$

$F$는 초당 frame 수, $S$는 길이(초)다. 30 fps, 10초, $224\times224$ RGB video만 해도 약 43 MiB다. Training에서는 입력뿐 아니라 각 layer의 activation과 gradient도 저장하므로 실제 GPU memory 부담은 이보다 훨씬 크다.

### **1.1 Video 규모와 clip sampling**

긴 원본을 한 번에 넣는 대신 짧은 clip을 뽑는다. 예를 들어 5 fps로 16 frame을 뽑으면 약 3.2초의 시간 구간이 된다.

![Video classification 문제에서 짧은 training clip과 여러 test clip으로 이어지는 전체 과정]({{ '/assets/img/posts/cs231n-lecture-10/animations/video-classification-clip-training.gif' | relative_url }})

Training에서는 시작 시점, frame 간격, spatial crop을 무작위로 바꾸며 clip을 sampling한다. Inference에서는 video의 여러 위치에서 clip을 뽑고 class probability를 평균한다.

$$
p(y\mid V)
\approx
\frac{1}{M}
\sum_{m=1}^{M}
p(y\mid X^{(m)})
$$

이 방식은 간단하고 강하지만 두 가지 한계가 있다.

첫째, 평균은 clip의 순서를 직접 모델링하지 않는다. 둘째, video-level label을 모든 sampled clip에 붙이면 실제 action이 없는 구간에도 같은 label이 들어갈 수 있다. 따라서 clip sampling은 단순한 전처리가 아니라 **어느 시간 구간을 학습 신호로 볼지 결정하는 과정**이다.

## **2. Single-frame CNN의 강한 baseline**

Video model을 만들기 전에 frame 하나만 보는 classifier부터 확인할 필요가 있다.

![달리는 사람의 연속 동작과 video-level action label]({{ '/assets/img/posts/cs231n-lecture-10/video/running-action.gif' | relative_url }})

Action dataset에는 동작 외의 단서도 많다.

- 수영장 배경과 수영 label
- 농구 코트와 basketball label
- 기타의 모양과 guitar-playing label
- 눈 덮인 산과 skiing label

Single-frame baseline은 dataset의 appearance shortcut 강도를 측정한다. 이후 temporal model의 개선이 실제 시간 정보에서 나온 것인지 판단할 비교 기준도 된다. 학습에서는 여러 frame을 독립적인 image sample로 사용하고 inference에서 class probability를 모은다.

$$
\hat p(y\mid V)
=
\frac{1}{T}
\sum_{t=1}^{T}
p(y\mid I_t)
$$

하지만 이 식은 frame의 순서를 바꿔도 값이 같다. 정적 장면과 물체는 잘 보지만 motion의 방향과 temporal ordering은 표현하지 못한다.

## **3. Temporal fusion의 위치**

시간 정보를 넣는 가장 직접적인 방법은 여러 frame의 feature를 한 지점에서 합치는 것이다. 중요한 차이는 **어디에서 합치는가**다.

![Single-frame CNN에서 late fusion, early fusion과 3D CNN으로 이어지는 시공간 결합 방식]({{ '/assets/img/posts/cs231n-lecture-10/animations/single-late-early-3d-fusion.gif' | relative_url }})

### **3.1 Late fusion의 high-level feature aggregation**

각 frame을 같은 2D CNN으로 처리하면 feature map

$$
F_t\in\mathbb{R}^{D\times H'\times W'}
$$

를 얻는다.

Concatenation은 시간 위치를 구분한다.

$$
z_{\mathrm{cat}}
=
[\operatorname{vec}(F_1);\cdots;\operatorname{vec}(F_T)]
\in\mathbb{R}^{TDH'W'}
$$

하지만 $T$뿐 아니라 남아 있는 spatial size만큼 classifier의 parameter 수가 커지고 보통 고정 길이를 요구한다.

Pooling 기반 late fusion은 시간과 공간을 함께 평균해 크기를 $D$로 유지한다.

$$
z_{\mathrm{pool}}
=
\frac{1}{TH'W'}
\sum_{t=1}^{T}
\sum_{h=1}^{H'}
\sum_{w=1}^{W'}
F_t[:,h,w]
$$

대신 순서를 잃는다. 더 근본적인 문제는 frame마다 깊은 feature를 만든 뒤에야 비교한다는 점이다. 발의 미세한 상하 이동처럼 작은 motion cue가 각 frame에서 독립적으로 추상화되는 동안 사라질 수 있다.

### **3.2 Early fusion의 첫-layer temporal collapse**

Early fusion은 시간을 channel 안으로 접는다.

$$
\widetilde X
\in
\mathbb{R}^{B\times (CT)\times H\times W}
$$

첫 2D convolution의 weight는 다음 shape를 갖는다.

$$
W_{\mathrm{early}}
\in
\mathbb{R}^{C_{\mathrm{out}}\times(CT)\times K_h\times K_w}
$$

모든 frame을 첫 layer에서 바로 비교하므로 저수준 motion을 볼 수 있다. 그러나 첫 layer 뒤에는 명시적인 $T$축이 남지 않는다. 또한 clip의 첫 번째, 두 번째, 세 번째 temporal slot마다 서로 다른 input-channel weight가 연결되므로, 같은 색 변화가 다른 시점에 나타나면 같은 detector를 그대로 이동시켜 쓸 수 없다.

### **3.3 3D convolution의 점진적 시공간 결합**

3D convolution은 짧은 temporal kernel을 공간과 시간에 함께 이동시킨다.

$$
W_{\mathrm{3D}}
\in
\mathbb{R}^{C_{\mathrm{out}}\times C_{\mathrm{in}}\times K_t\times K_h\times K_w}
$$

$$
Y
\in
\mathbb{R}^{B\times C_{\mathrm{out}}\times T'\times H'\times W'}
$$

Early fusion과 달리 output에 시간축이 남는다. 얕은 layer는 짧고 작은 움직임을 보고, 깊은 layer는 앞선 feature를 다시 결합하며 더 긴 action pattern을 본다. 여기서 3D convolution은 개별 **연산**이고, 여러 layer에 걸쳐 temporal receptive field를 천천히 넓히는 설계가 **slow fusion**이다.

![Late·early·3D fusion에서 temporal receptive field가 넓어지는 위치의 전체 비교]({{ '/assets/img/posts/cs231n-lecture-10/animations/temporal-receptive-field-comparison.gif' | relative_url }})

| 방식 | 시간 결합 시점 | 명시적 $T$축 | 주요 한계 |
|---|---|---:|---|
| Single frame | 결합 없음 | frame별 분리 | motion과 순서 부재 |
| Late fusion | 깊은 feature 이후 | 결합 전까지 유지 | 작은 motion 소실, pooling의 순서 손실 |
| Early fusion | 첫 layer | 첫 layer 뒤 소실 | 고정 $T$, temporal position별 weight |
| 3D CNN | 모든 layer에서 점진적 | layer마다 유지 | 큰 계산량과 activation memory |

### **3.4 Temporal receptive field와 shift equivariance**

Early-fusion filter는 clip 전체의 절대 위치에 묶인다. 반면 3D kernel은 $t$, $h$, $w$를 따라 이동하므로 같은 motion pattern을 clip의 여러 시점에서 같은 weight로 검출한다.

![Early-fusion 2D convolution과 시간축을 따라 이동하는 3D convolution의 차이]({{ '/assets/img/posts/cs231n-lecture-10/animations/early-fusion-vs-3d-convolution.gif' | relative_url }})

3D convolution은 temporal-shift **equivariance**를 갖는다. Input motion이 시간축에서 이동하면 feature response도 함께 이동하고, global pooling이나 aggregation이 위치 차이를 지우면 최종 prediction은 shift에 덜 민감해진다. 이 구분은 [Lecture 5의 translation equivariance와 invariance](/posts/cs231n-lecture-5/#10-translation-equivariance와-invariance의-차이)와 같다.

첫 layer의 3D kernel은 작은 video clip처럼 재생할 수 있다. 정적 color·edge pattern뿐 아니라 특정 방향으로 움직이는 edge에 반응하는 filter도 나타난다.

![시간에 따라 변하는 first-layer 3D convolution filter들의 motion pattern]({{ '/assets/img/posts/cs231n-lecture-10/video/learned-3d-filters.gif' | relative_url }})

## **4. 3D CNN architecture의 확장**

### **4.1 C3D의 3×3×3 block과 계산 비용**

C3D는 VGG와 비슷한 깊은 stack에서 $3\times3\times3$ convolution을 반복한다. 초기 pooling은 temporal size를 너무 일찍 줄이지 않도록 $(1,2,2)$ kernel을 사용하고, 이후 block에서는 $(2,2,2)$ pooling으로 시간과 공간을 함께 축소한다.

![Sports-1M의 초기 video model에서 C3D architecture와 계산 비용으로 이어지는 흐름]({{ '/assets/img/posts/cs231n-lecture-10/animations/c3d-history-and-cost.gif' | relative_url }})

3D kernel의 parameter 수는 bias를 제외하면 다음과 같다.

$$
\#W
=
C_{\mathrm{out}}C_{\mathrm{in}}K_tK_hK_w
$$

같은 $C_{\mathrm{in}}$, $C_{\mathrm{out}}$과 spatial kernel 크기라면 3D convolution은 2D convolution보다 $K_t$배 많은 weight를 갖는다. 각 layer의 activation도 $T'\times H'\times W'$를 유지하므로 FLOPs와 training memory가 빠르게 커진다. 그래서 video architecture에서는 temporal downsampling의 위치, clip 길이, input resolution이 함께 설계 변수다.

Sports-1M 비교에서 single-frame model은 이미 강한 baseline이었고, 3D modeling의 개선에는 더 큰 계산 비용이 따랐다. Temporal architecture는 정확도뿐 아니라 appearance shortcut을 넘어선 motion modeling과 계산량을 함께 평가해야 한다.

Sports-1M은 원본 video가 아니라 YouTube URL 목록으로 배포됐다. 영상이 삭제되거나 바뀌면 같은 dataset을 다시 구성하기 어려워지는 link rot 문제가 생긴다. 당시 C3D를 대규모로 다시 학습하는 비용도 컸기 때문에 공개된 pretrained weight를 고정 feature extractor로 사용하는 방식이 널리 쓰였다.

### **4.2 I3D의 2D architecture·weight inflation**

성공한 2D architecture와 pretrained weight를 video model 초기화에 재사용할 수 있다. I3D의 핵심이 이 **inflation**이다.

2D kernel을 다음처럼 두자.

$$
W_{\mathrm{2D}}
\in
\mathbb{R}^{C_{\mathrm{out}}\times C_{\mathrm{in}}\times K_h\times K_w}
$$

시간축으로 $K_t$번 복사한 뒤 $K_t$로 나눈다.

$$
W_{\mathrm{3D}}[:,:, \tau,:,:]
=
\frac{1}{K_t}W_{\mathrm{2D}},
\qquad
\tau=1,\ldots,K_t
$$

![2D Inception architecture와 pretrained kernel을 3D I3D로 확장하는 전체 과정]({{ '/assets/img/posts/cs231n-lecture-10/animations/i3d-weight-inflation.gif' | relative_url }})

Temporal window의 모든 frame이 같은 constant clip이라면 각 slice의 response 합이 원래 2D response와 같아진다.

$$
\sum_{\tau=1}^{K_t}
\frac{1}{K_t}
\bigl(W_{\mathrm{2D}}*I\bigr)
=
W_{\mathrm{2D}}*I
$$

Constant-clip equivalence는 초기화 시점과 temporal padding의 경계 효과가 없는 위치에서 성립한다. Fine-tuning이 진행되면 temporal slice의 weight는 서로 다른 motion pattern을 학습한다.

[Lecture 6의 transfer learning](/posts/cs231n-lecture-6/#9-데이터-양과-domain-차이에-따른-transfer-learning-전략)이 2D backbone의 feature를 새 dataset에 옮겼다면, I3D는 architecture와 kernel에 시간축까지 만들어 옮기는 방법이다.

## **5. Appearance와 motion의 분리**

RGB texture를 거의 없애고 관절 위치에 작은 점만 남겨도 사람은 걷기, 앉기, 상호작용을 알아볼 수 있다.

![검은 배경의 관절 점 이동만으로 사람 동작이 드러나는 point-light motion]({{ '/assets/img/posts/cs231n-lecture-10/video/point-light-motion.gif' | relative_url }})

이 예시는 texture 없이도 motion이 강한 단서라는 사실을 보여 준다.

### **5.1 Optical flow의 displacement field**

Optical flow는 인접한 두 frame에서 밝기 pattern의 겉보기 이동을 $(d_x,d_y)$ field로 나타낸다.

$$
F_t(x,y)
=
\bigl(d_x(x,y),d_y(x,y)\bigr)
$$

고전적인 출발점은 brightness constancy다.

$$
I_{t+1}(x+d_x,y+d_y)
\approx
I_t(x,y)
$$

Brightness constancy는 occlusion, illumination change, reflection, motion blur와 low-texture region에서 깨지며, estimated flow에는 camera motion도 함께 포함된다.

### **5.2 Two-stream network의 spatial·temporal branch**

$T$개 frame에서 인접 pair의 horizontal·vertical flow를 쌓으면 temporal-stream input은 다음처럼 쓸 수 있다.

$$
X_{\mathrm{flow}}
\in
\mathbb{R}^{2(T-1)\times H\times W}
$$

Spatial stream은 RGB appearance를 보고 temporal stream은 stacked optical flow를 본다. 마지막에 두 branch의 class score를 결합한다.

![Point-light motion에서 optical flow의 두 성분과 two-stream network까지의 전체 전개]({{ '/assets/img/posts/cs231n-lecture-10/animations/optical-flow-two-stream.gif' | relative_url }})

이 분리는 inductive bias를 명확하게 만든다.

- Spatial stream: 사람, 도구, 장소와 장면 context
- Temporal stream: pixel displacement의 방향과 속도

Two-stream 구조의 핵심은 어느 한 신호의 우월성이 아니라 appearance와 motion의 상보적 결합에 있다.

## **6. Long-term temporal structure의 recurrent modeling**

3D CNN의 temporal receptive field는 layer 수와 kernel 크기로 정해진다. 긴 video 전체의 사건 순서를 다루려면 짧은 clip feature를 sequence model에 넣는 방식이 자연스럽다.

### **6.1 CNN clip feature와 recurrent aggregation**

Frame 또는 clip $X_t$에서 CNN feature $z_t$를 만들고 recurrent state를 갱신한다.

$$
z_t=\phi_{\mathrm{CNN}}(X_t),
\qquad
h_t=f(h_{t-1},z_t)
$$

![짧은 CNN feature에서 many-to-one·many-to-many recurrent aggregation까지의 전체 흐름]({{ '/assets/img/posts/cs231n-lecture-10/animations/cnn-rnn-long-term-structure.gif' | relative_url }})

Many-to-one은 마지막 state로 video label을 만들고, many-to-many는 timestep마다 prediction을 만든다. CNN을 end-to-end로 함께 학습하면 feature가 task에 맞게 바뀌지만 activation memory가 크다. 미리 계산한 CNN feature를 저장하고 CNN을 고정하면 학습은 가벼워지지만 visual representation을 함께 개선할 수 없다.

[Lecture 7의 RNN·LSTM·BPTT](/posts/cs231n-lecture-7/)에서 다룬 gate, gradient와 sequence optimization 문제는 visual feature sequence에도 적용된다.

### **6.2 Recurrent convolution의 spatial hidden state**

Spatial feature map을 vector로 flatten해 fully connected RNN에 넣으면 공간 배치가 직접적인 tensor 구조로 남지 않는다. Recurrent convolution은 matrix multiplication을 2D convolution으로 바꿔 hidden state를 $C\times H\times W$ 형태로 유지한다.

$$
H_t^{(\ell)}
=
\tanh\left(
W_h^{(\ell)}*H_{t-1}^{(\ell)}
+
W_x^{(\ell)}*H_t^{(\ell-1)}
+
b^{(\ell)}
\right)
$$

$*$는 2D convolution이다. 한 state는 같은 layer의 이전 시간 $H_{t-1}^{(\ell)}$과 이전 layer의 현재 시간 $H_t^{(\ell-1)}$을 함께 받는다.

![Multi-layer RNN에서 spatial hidden state를 보존하는 recurrent convolution까지의 전체 조립]({{ '/assets/img/posts/cs231n-lecture-10/animations/recurrent-convolution.gif' | relative_url }})

### **6.3 Sequential recurrence의 병렬화 제약**

Recurrent state에는 형식상 고정된 temporal receptive-field 상한이 없지만, effective memory는 hidden capacity, vanishing gradient와 truncated BPTT로 제한된다.

또한 $h_t$를 계산하려면 $h_{t-1}$이 필요하다. Batch·channel·spatial convolution은 병렬화할 수 있지만 한 sequence의 시간축 계산은 완전히 동시에 실행하기 어렵다. 이 순차 dependency가 긴 video에서 recurrence가 느려지는 핵심 이유다.

## **7. Global space-time interaction**

Local 3D kernel은 가까운 frame과 pixel부터 연결한다. 멀리 떨어진 두 시공간 위치를 한 layer에서 직접 연결하려면 feature tensor를 token 집합으로 펼쳐 self-attention을 적용할 수 있다.

### **7.1 Non-local block의 spatio-temporal self-attention**

$$
X
\in
\mathbb{R}^{C\times T\times H\times W},
\qquad
N=THW
$$

시공간 위치를 펼친 row-token representation을

$$
\widetilde X\in\mathbb{R}^{N\times C}
$$

로 두자. $1\times1\times1$ convolution에 해당하는 channel projection으로 $Q,K,V\in\mathbb{R}^{N\times d}$를 얻는다.

Channel dimension $d$를 기준으로 scale한 dot-product notation은 다음과 같다.

$$
A
=
\operatorname{softmax}
\left(
\frac{QK^\top}{\sqrt d}
\right)
\in
\mathbb{R}^{N\times N}
$$

$$
Z=AV,
\qquad
Z\in\mathbb{R}^{N\times d}
$$

$$
W_z\in\mathbb{R}^{d\times C},
\qquad
\widetilde Y=\widetilde X+ZW_z
$$

![시공간 feature에서 Q·K·V와 attention map을 거쳐 residual output이 완성되는 non-local block]({{ '/assets/img/posts/cs231n-lecture-10/animations/spatiotemporal-nonlocal-block.gif' | relative_url }})

$ZW_z$는 원래 channel 크기로 projection한 뒤 input과 residual addition하고, $\widetilde Y$를 다시 $C\times T\times H\times W$로 reshape한다. 이 global interaction은 [Lecture 8의 self-attention](/posts/cs231n-lecture-8/#4-self-attention과-입력-집합-내부의-정보-교환)과 연결되지만, positional encoding·MLP·normalization은 별도의 Transformer 구성 요소다. Attention map은 $(THW)\times(THW)$이므로 global connection의 비용은 다음 Video Transformer의 token 설계로 이어진다.

---

## **8. Video Transformer의 space-time token**

Video를 $P_t\times P_h\times P_w$ tubelet으로 나누면 token 수는 다음과 같다.

$$
N
=
\frac{T}{P_t}
\frac{H}{P_h}
\frac{W}{P_w}
$$

모든 token 사이 joint attention은 $O(N^2)$이므로 긴 시간과 높은 해상도를 동시에 쓰기 어렵다.

### **8.1 Joint attention의 quadratic cost와 factorization**

Frame마다 spatial token이 $S$개라면 joint space-time attention의 pair 수는

$$
O\bigl((TS)^2\bigr)
$$

이다. Space attention과 time attention을 나누면 대략

$$
O(TS^2+ST^2)
$$

로 바뀐다. 모든 위치가 한 번에 직접 연결되지는 않지만 한 block 안에서 spatial mixing과 temporal mixing을 차례로 수행할 수 있다.

### **8.2 Token pooling과 masked pretraining**

![Space-time factorization, multiscale token pooling과 masked video pretraining의 설계 방향]({{ '/assets/img/posts/cs231n-lecture-10/animations/video-transformer-directions.gif' | relative_url }})

Video Transformer의 대표적인 계산 절약 방향은 세 가지다.

- Factorized attention: space와 time의 attention 분리
- Multiscale pooling: layer가 깊어질수록 token 수 축소
- Masked pretraining: tubelet 대부분을 가리고 남은 token으로 representation 학습

높은 benchmark accuracy를 attention 하나의 효과로만 해석하면 안 된다. Model scale, pretraining data, masking recipe, input view 수가 함께 바뀐다. 중요한 흐름은 video에서도 **global interaction을 얻는 대신 token 수를 적극적으로 줄이는 설계**가 필요하다는 점이다.

## **9. Video representation의 시각화**

특정 class score가 커지도록 RGB input과 optical-flow input을 gradient ascent로 최적화하면 model이 선호하는 appearance와 motion pattern을 합성할 수 있다.

$$
X^\star
=
\arg\max_X
\left(
s_c(X)-\lambda R(X)
\right)
$$

$s_c$는 class logit이고 $R(X)$는 너무 거친 pattern을 억제하는 regularizer다. Flow의 spatial variation에 서로 다른 penalty를 주면 느린 motion과 빠른 motion 선호를 나눠 볼 수 있다.

![Appearance와 slow·fast motion pattern이 action class를 드러내는 video-model visualization]({{ '/assets/img/posts/cs231n-lecture-10/animations/video-model-visualization.gif' | relative_url }})

[Lecture 9의 input-gradient saliency](/posts/cs231n-lecture-9/#11-input-gradient-saliency)는 실제 입력 주변의 local sensitivity를 계산했다. Activation maximization은 반대로 class score를 키우는 입력을 합성하며, 결과는 regularizer와 initialization에 의존하는 representation 진단이다.

## **10. Clip classification 이후의 structured prediction**

Trimmed clip 하나에 label 하나를 붙이는 문제만으로는 긴 실제 video를 충분히 표현하기 어렵다.

![Short-clip classification에서 temporal localization과 spatio-temporal detection으로의 확장]({{ '/assets/img/posts/cs231n-lecture-10/animations/dense-video-tasks.gif' | relative_url }})

### **10.1 Temporal action localization의 시간 구간**

Temporal localization은 긴 untrimmed video에서 action의 시작과 끝을 찾는다.

$$
\mathcal Y
=
\left\{
([s_i,e_i],c_i)
\right\}_{i=1}^{M}
$$

Image detection의 region proposal을 1D time axis로 옮긴 것처럼 볼 수 있다. 후보 temporal interval을 만들고 action class와 boundary offset을 예측한다. [Lecture 9의 Faster R-CNN](/posts/cs231n-lecture-9/)에서 spatial box를 다루던 구조가 시간 구간으로 이어지는 연결이다.

### **10.2 Spatio-temporal detection의 공간·시간 tube**

Spatio-temporal detection은 사람을 공간에서 찾는 동시에 시간에 따른 action을 붙인다.

$$
\mathcal T_i
=
\left\{
(t,b_{i,t},\mathbf c_{i,t})
\right\}_{t=s_i}^{e_i}
$$

$b_{i,t}$는 frame $t$에서의 person box이고 $\mathbf c_{i,t}$는 action label이다. 한 사람이 동시에 “앉아 있음”, “다른 사람을 봄”, “물체를 잡음”을 수행할 수 있으므로 multi-label prediction이 자연스럽다.

## **11. Audio-visual video understanding**

Video의 시간 정보는 RGB frame에만 있지 않다. 입 모양과 음성, 악기 움직임과 소리처럼 서로 동기화된 modality도 같은 사건을 설명한다.

### **11.1 McGurk effect의 cross-modal perception**

같은 음성도 함께 보이는 입 모양에 따라 다르게 지각될 수 있다. 이는 auditory cue와 visual cue가 독립적으로 끝나는 것이 아니라 perceptual representation에서 결합된다는 예다.

![서로 다른 입 모양과 음성 cue가 결합되는 McGurk effect의 시각적 구성]({{ '/assets/img/posts/cs231n-lecture-10/animations/mcgurk-multisensory-fusion.gif' | relative_url }})

핵심은 modality score를 마지막에 합치는 것보다 **시간적으로 맞는 audio·visual feature를 대응시키는 것**이다.

### **11.2 Visual guidance 기반 audio source separation**

여러 source가 섞인 waveform을

$$
s(t)=\sum_{k=1}^{K}s_k(t)
$$

라고 하자. 이 waveform의 short-time Fourier transform을 $S$라 두면, video에 보이는 speaker나 instrument를 조건으로 target source의 spectrogram mask를 예측할 수 있다.

$$
\widehat S_k
=
M_k(V,S)\odot S
$$

![혼합 음성에서 보이는 화자와 악기를 조건으로 source를 분리하는 전체 흐름]({{ '/assets/img/posts/cs231n-lecture-10/animations/visual-audio-source-separation.gif' | relative_url }})

Visual feature는 얼굴·입 움직임과 악기의 형태로 target source를 지정하고, separator는 mixture audio에서 해당 component를 추정한다. Off-screen source, 유사한 visual source와 synchronization 오류는 separation ambiguity를 키운다.

### **11.3 Audio·video token의 multimodal fusion**

Video patch와 audio spectrogram patch를 각각 token으로 만든 뒤 cross-attention이나 shared Transformer로 결합할 수 있다. 좋은 representation은 다음 두 성질을 함께 필요로 한다.

- Synchronization: 같은 사건에서 나온 audio·visual 변화의 시간적 정렬
- Complementarity: 한 modality에 없는 정보를 다른 modality가 보충하는 구조

두 stream의 모든 token을 무조건 합치는 방식은 계산량도 크다. 어떤 modality와 시간 구간이 현재 prediction에 필요한지 선택하는 문제가 다음 단계로 이어진다.

## **12. Long-video understanding의 선택적 계산**

긴 video의 모든 clip을 같은 비싼 model로 처리한 뒤 평균하는 방식은 중요한 순간과 무의미한 구간에 같은 계산을 쓴다.

![모든 clip 처리에서 salient sampling, audio preview, egocentric understanding과 Video-LLM으로 이어지는 확장]({{ '/assets/img/posts/cs231n-lecture-10/animations/efficient-video-understanding.gif' | relative_url }})

### **12.1 Efficient backbone과 streaming inference**

효율화에는 서로 다른 축이 있다.

- Clip당 비용 감소: channel·depth·resolution·temporal duration의 균형 조정
- Streaming: 미래 frame을 기다리지 않고 state를 갱신하는 causal computation
- Token 축소: pooling, sparse attention, early feature compression

같은 FLOPs라도 전체 video를 여러 번 보는 multi-view inference와 한 번만 흐르게 하는 streaming inference의 latency는 다르다.

### **12.2 Salient clip·modality selection**

먼저 저렴한 sampler가 중요한 clip을 고르고 무거운 model은 선택된 구간만 처리할 수 있다. Audio처럼 비교적 싼 modality를 preview signal로 써 “볼 가치가 있는” 시점을 고르는 방법도 가능하다.

하지만 선택적 계산에는 누락 위험이 생긴다. 짧고 드문 사건을 sampler가 건너뛰면 뒤의 model은 복구할 수 없다. 따라서 efficiency는 단순한 평균 FLOPs뿐 아니라 중요한 event를 놓치지 않는 recall과 함께 평가해야 한다.

### **12.3 Egocentric video와 Video-LLM의 확장**

Smart glasses의 egocentric camera와 microphone array는 사용자가 보는 장면, 말하는 사람의 방향, 대화 흐름을 함께 담는다. 핵심 task는 “누가 누구에게 말하는가”처럼 시간에 따라 변하는 관계의 표현이다.

Video-language model은 sampled visual token을 language-model embedding space로 projection하고 질문에 text로 답한다. 입력 frame 수가 늘면 visual token 수와 attention 비용도 함께 증가한다. Token budget 안에서 사건을 선택하고 순서를 보존하며 audio와 subtitle을 정렬하는 문제가 남는다.

## **13. PyTorch 기반 video tensor 검산**

### **13.1 Conv3d output shape와 parameter 수**

한 축의 convolution output size는 다음과 같다.

$$
L_{\mathrm{out}}
=
\left\lfloor
\frac{
L_{\mathrm{in}}+2P-D(K-1)-1
}{S}
+1
\right\rfloor
$$

시간과 두 spatial axis에 각각 같은 식을 적용한다.

```python
import torch
from torch import nn

x = torch.randn(2, 3, 16, 112, 112)  # [B, C, T, H, W]

conv = nn.Conv3d(
    in_channels=3,
    out_channels=64,
    kernel_size=(3, 3, 3),
    stride=(1, 2, 2),
    padding=(1, 1, 1),
    bias=False,
)

y = conv(x)
print(y.shape)
# torch.Size([2, 64, 16, 56, 56])

parameter_count = sum(p.numel() for p in conv.parameters())
print(parameter_count)
# 64 * 3 * 3 * 3 * 3 = 5184
```

Temporal stride가 1이고 padding이 1이므로 $T=16$은 유지된다. Spatial stride가 2라서 $112\times112$는 $56\times56$으로 줄어든다.

### **13.2 Inflated kernel의 constant-video equivalence**

```python
import torch
import torch.nn.functional as F

torch.manual_seed(0)

weight_2d = torch.randn(8, 3, 3, 3)
kernel_t = 3

weight_3d = (
    weight_2d.unsqueeze(2)
    .repeat(1, 1, kernel_t, 1, 1)
    / kernel_t
)

image = torch.randn(2, 3, 16, 16)
constant_clip = image.unsqueeze(2).repeat(1, 1, kernel_t, 1, 1)

y_2d = F.conv2d(image, weight_2d, padding=1)
y_3d = F.conv3d(
    constant_clip,
    weight_3d,
    padding=(0, 1, 1),
)

torch.testing.assert_close(y_3d[:, :, 0], y_2d)
print(y_3d.shape)
# torch.Size([2, 8, 1, 16, 16])
```

시간축 padding 없이 kernel이 constant clip 전체를 한 번 덮는 조건에서 3D response가 2D response와 일치한다.

### **13.3 Space-time attention의 token shape**

```python
import math
import torch
from torch import nn

B, C, T, H, W = 2, 128, 4, 7, 7
heads = 4
head_dim = C // heads

x = torch.randn(B, C, T, H, W)
tokens = x.flatten(2).transpose(1, 2)  # [B, THW, C]

qkv = nn.Linear(C, 3 * C, bias=False)(tokens)
q, k, v = qkv.chunk(3, dim=-1)

def split_heads(z):
    return z.view(B, T * H * W, heads, head_dim).transpose(1, 2)

q, k, v = map(split_heads, (q, k, v))
attention = torch.softmax(
    q @ k.transpose(-2, -1) / math.sqrt(head_dim),
    dim=-1,
)
output = attention @ v

print(tokens.shape)
# torch.Size([2, 196, 128])
print(attention.shape)
# torch.Size([2, 4, 196, 196])
print(output.shape)
# torch.Size([2, 4, 196, 32])
```

$T=4$, $H=W=7$이면 token은 $196$개다. Head마다 $196\times196$ attention map이 생긴다는 사실이 global space-time attention의 비용을 직접 보여 준다.

## **14. 정리**

Video understanding은 다음 설계 축으로 정리된다.

1. 긴 raw video에서 학습 가능한 short clip의 선택
2. Single-frame baseline을 통한 appearance shortcut의 측정
3. Late·early·3D fusion의 시간 결합 위치 선택
4. 3D convolution의 temporal weight sharing과 receptive-field 확장
5. RGB appearance와 optical-flow motion의 분리
6. Recurrent state 또는 non-local attention을 통한 장기 관계 연결
7. I3D inflation을 통한 2D architecture·weight의 재사용
8. Factorization·pooling·masking을 통한 Video Transformer의 token 비용 제어
9. Localization, audio-visual fusion, selective sampling으로의 task 확장

$$
\boxed{
\text{Video understanding}
=
\text{spatial representation}
+
\text{temporal interaction}
+
\text{sampling policy}
+
\text{multimodal context}
}
$$

좋은 video model은 시간축을 무조건 길게 보는 model이 아니다. **필요한 시간 범위를 보존하고, 같은 motion computation을 재사용하며, 중요한 구간과 modality에 계산을 집중하는 model**이다.
